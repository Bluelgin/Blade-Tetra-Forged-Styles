# Blade Tetra: Forged Styles 1.4.4

The awakened souls have discovered teamwork. They still refuse to form a four-person party.

- Added pairwise soul fusion for Akatsuki, Kyouka Suigetsu, Senbonzakura and Raikiri.
- A fused inscription keeps both awakened abilities without stacking their stats—or letting bonus attacks start an infinite argument.
- Fusion options now appear only when the blade remembers both legacies, and only valid upgrades are shown.
- Fusion forging now uses the installed soul plus one matching soul material.

Short version: two souls, one sword, considerably less menu soup.
