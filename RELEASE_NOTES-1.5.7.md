# Blade Tetra: Forged Styles 1.5.7

Prettier blades. Mikage now judges you from your inventory, too.

- Removed custom SA modifiers; builds now use a soul core, a primary technique and a secondary technique. Existing inscriptions remain readable; old modifiers no longer apply.
- Rebalanced composed SA damage: 85% primary / 65% secondary base scaling, with up to a 15% core bonus based on live Tetra material data, including MMT materials.
- Higher-tier techniques require better hammers. Workbench and holographic previews now show core bonuses and both phase multipliers.
- Shortened orb tooltips and moved detailed multipliers behind Alt. The orb now uses a color-shifting native ProudSoul Sphere appearance.
- Refreshed journal, record, clue and selected ritual-item icons, including a fox-style broken mask.
- Added material-tinted flowing backplates for ordinary blades and a Mikage expression for active Awakened Akatsuki. Brighter inventory blades, with the native durability-frame tint restored.
- Fixed a summoned-sword null-hit crash and Akatsuki resonance cleanup conflicts. Hardened dialogue decoding, packet directions and Raikiri shutdown cleanup.
- Fixed Mikage's flame-wall crash when a lethal hit sends a player home. Failed challenges now extinguish fire and extend brief damage immunity.

Mikage may send you home. The server should stay where it is.
