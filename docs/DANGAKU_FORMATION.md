# 断岳流 · 阵型操纵与蓄力横扫

## 1. 核心定义

断岳不再是“系统自动交替纵劈/横扫”的重攻击流派，而是：

`左键断阵 + 右键整阵 + 长按右键开岳`

玩家的主要资源不是层数或标记，而是**敌人的实际位置**。

- 左键：纵劈 / Cleave，窄、重、有霸体；
- 右键短按：普通横扫 / Sweep，低伤害，快速把敌人整理到玩家前方；
- 右键长按：蓄力大横扫，控制更大的战场；
- 敌群被压紧后，纵劈读取当前阵型并获得小幅群体收益。

本传与居合不变；连舞仍按 `RENGEKI_SHORT_STEP.md` 独立运行。

## 2. 输入分工

断岳普通地面输入不再自动 `Cleave ↔ Sweep`。

- `L_CLICK`：选择 `dangaku_cleave`；
- 普通 `R_CLICK`：Combo 根返回 `NONE`，利用 Resharped 自带 `startUsingItem()` 进入持有状态；
- 松手由 `DangakuFormationHandler` 接管：
  - `< 8 tick`：普通横扫；
  - `>= 8 tick`：按当前蓄力值释放 `dangaku_charged_sweep`。

潜行方向技与空中技仍走 Resharped 原生分支。

`StyleInputBuffer` 不再保存断岳的自动纵横切换，避免旧逻辑抢掉右键蓄力。

## 3. 蓄力曲线

### 3.1 时间

- 满蓄：`44 tick`（约 `2.2 s`）；
- 满蓄宽限：`5 tick`；
- 超过宽限后：蓄力值按固定速度单向衰减；
- 最低：`25%`；
- 不会重新循环回 `100%`。

也就是说，第一次达到满蓄是唯一最佳释放窗口。

### 3.2 HUD

客户端直接读取原生 `getTicksUsingItem()`，使用与服务器相同的 `DangakuChargeMath`：

- 普通蓄力：显示百分比进度条；
- 满蓄宽限：显示 `◆`；
- 过蓄衰减：显示 `↓`，进度条同步回落。

HUD 没有战斗权威，也不新增同步包。

## 4. 面板动态缩放

面板伤害使用柔性平方根缩放：

`panelPower = clamp(sqrt(panelDamage / 24), 0.75, 1.50)`

因此高面板仍能扩大断岳的战场控制能力，但不会线性失控。

### 4.1 满蓄范围

满蓄大横扫范围：

- 低面板基线：约 `8.5` 格；
- 高面板硬上限：`12.0` 格。

未满蓄时，实际范围从 `5.5` 格向对应满蓄范围插值。

### 4.2 伤害

大横扫仍然是“整阵技”，不是主要爆发技。

- ratio 低点约 `0.55x`；
- 满蓄随面板柔性提高，约 `0.72x → 0.86x`；
- 实际伤害仍使用 Resharped 的正常玩家/武器面板路径。

普通 Sweep 在旧 `0.92x` 基础上再乘 `0.82`，最终约 `0.75x`；Cleave 在旧 `1.12x` 基础上再乘 `1.05`，最终约 `1.18x`。

## 5. 整阵

普通 Sweep 命中后，目标不会单纯从玩家身边炸开，而是朝玩家前方约 `2.7` 格的收束点移动。

大横扫使用更远的动态收束点：范围越大，收束点越靠前。

位移考虑目标的击退抗性；高抗性/Boss 不会被无条件强拉。

## 6. 大横扫

大横扫使用独立的 visual-only Combo 节点：

- 复用原生 Sweep 动作；
- 释放后延迟 `4 tick` 命中，使伤害落在挥刀节拍而不是松手瞬间；
- 自己做目标选择与 melee 命中；
- 约 `±135°` 大扇区；
- 最多 `24` 个合法目标；
- 要求 LOS；
- 使用 `SlashBladeTargetingConditions + AttackablePredicate`；
- `forceHit=false`；
- `resetHit=false`；
- 不清除其他攻击留下的 hurt window。

视觉刀光为 ownerless `EntitySlashEffect`，只负责表现，不复制成额外 areaAttack。

## 7. 断阵

旧断岳是：

`Cleave 命中 → 给目标写 BROKEN_STANCE_* NBT → 下一次本人攻击 +5% → 清理`

新断岳不再依赖这个标记作为玩法。

纵劈命中时直接读取目标周围 `1.8` 格内的合法敌群：

- 至少 `3` 个目标形成紧密群体时，本次纵劈获得约 `10%` 的阵型奖励；
- 没有层数；
- 没有计时器；
- 不需要记住“是不是刚刚被横扫过”。

位置本身就是状态。

当前迁移层会在旧 `StyleCombatHandler` 写入破势 tag 后立即清理，并在伤害事件前再次清理，确保旧 +5% 不再实际参与伤害。后续如果整理 `StyleCombatHandler`，可以直接删除旧破势字段/清理分支，不需要改变新玩法。

## 8. Runtime 检查

1. 地面左键能直接进入纵劈，不再被强制安排下一刀为横扫。
2. 普通地面右键按下时不立即挥刀。
3. `<8 tick` 松开触发普通 Sweep。
4. 长按 HUD 从 0% 向 100% 上升。
5. 约 2.2 秒进入满蓄，保持约 0.25 秒宽限。
6. 继续按住后进度条单向下降，不重新循环到 100%。
7. 满蓄低面板范围约 8.5+，高面板不超过 12 格。
8. 大横扫最多处理 24 个合法目标，不能隔墙命中。
9. 普通/蓄力 Sweep 都能明显把敌群压向玩家前方收束区。
10. 高击退抗性的目标受到较弱位移。
11. 聚成至少 3 个目标后纵劈能获得断阵收益。
12. 大横扫不会 `forceHit/resetHit` 清掉已有 i-frame。
13. 断岳普通蓄力松手不会同时触发 Slash Art。
14. 潜行方向技、空中技仍保持原生路径。
15. 不新增永久 charge NBT，也不新增网络包。
