# 拔刀剑：百构流派 1.2.1

适用于 Minecraft 1.20.1、Forge 47.x、Tetra 6.10.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

## 流派平衡

- 连舞流解除额外 10% 伤害折减；胁差刀身伤害倍率由 0.72 提高至 0.78，材料耐久倍率由 0.7 提高至 1.1，固定耐久修正由 -35 调整为 -10。
- 断岳纵劈倍率由 1.35 调整为 1.18，横斩由 1.08 调整为 0.95，破势追击由 1.15 调整为 1.08；范围、击退和霸体保持不变。
- 居合追斩与返斩由 1.15 提高至 1.22，收束斩由 1.40 提高至 1.45；普通拔刀与完美拔刀保持 1.60 与 2.00。
- 收刀蓄势满 6 tick 后新增轻微刀镡提示；完美拔刀新增更窄、更亮的刀光、暴击闪光和独立音效。
