# Blade Tetra 1.3.3

## JEI residual-page compatibility

- JEI now recognizes every smithing clue as a distinct NBT-backed subtype.
- Shoshin, Bairen, Bansho, Raikiri, Akatsuki, Kyouka, and Senbonzakura pages
  can all appear independently in JEI search and retain the correct page data
  when obtained through JEI's cheat mode.
- JEI remains an optional client-side integration and is not required to run
  Blade Tetra.
