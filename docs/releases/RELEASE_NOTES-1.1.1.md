# 拔刀剑：百构流派 1.1.1

适用于 Minecraft 1.20.1、Forge 47.4.0、Tetra 6.10.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

## 本次更新

- 扩展普通锻造工艺与小型精加工，让富余完整度能够继续投入部件强化。
- 依照“玩家是顶级锻造师”的标准重制材料表面：移除刀身散点和杂乱噪声，改用干净抛光面与一条轻微弯曲的连续锻流线。
- 完善晶体、黑曜石、龙钢等特殊材料的连续纹理与发光表现。
- 修复模块化拔刀剑物品栏耐久背板透明或统一呈紫色的问题；背板现在会正确跟随刀身材料着色，未附魔武器同样有效。
- 保留此前对手持普通模块刀掉帧问题的修复：无发光结果会被缓存，不再逐帧重复生成和扫描纹理。
