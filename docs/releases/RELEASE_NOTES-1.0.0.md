# Blade Tetra: Forged Styles 1.0.0

Minecraft 1.20.1 · Forge 47.x

## English changelog

Blade Tetra 1.0.0 is the first feature-frozen stable release, bringing Tetra's
modular craftsmanship to SlashBlade: Resharped.

- Forge one persistent modular SlashBlade across eight component slots:
  blade, tsuka, tsuba, saya, habaki, kashira, fuller, and soul inscription.
- Choose Iaido, Rengeki, or Dangaku through the installed blade construction.
- Preserve SlashBlade ownership, kill count, durability, break state, special
  attacks, and combo state while repairing and honing through Tetra.
- Render material-aware 512px blade textures, authored component geometry,
  preset or banner saya artwork, material emission, and awakened soul glow.
- Discover the Journal of Forged Blades and eight hidden legacies: Beginner's
  Heart, Hundred-Forged, Myriad Forms, Raikiri, Akatsuki, Kyouka Suigetsu,
  Senbonzakura, and NBT Sage.
- Optionally bind an awakened Akatsuki to a persistent Contract Blade spirit.
- Fix severe frame loss when holding an ordinary non-luminous modular blade.
  Empty emission masks are now cached instead of rebuilding a 512px atlas on
  every render pass.
- Include a command-only developer talisman for safe legacy testing. It has no
  recipe or creative-tab entry and is disabled for ordinary packaged games.

### Required

- Minecraft 1.20.1
- Forge 47.x (built with 47.4.0)
- Tetra 6.10.0+
- mutil 6.2.0+
- SlashBlade: Resharped 1.9.63+

### Optional

- Player Animator 1.0.2-rc1+
- Contract Blade Core 0.1.0-beta.8+ for the Akatsuki contract spirit

The Akatsuki Winefox model pack is a separate optional download with its own
CC BY-NC-SA 4.0 license and credits. It is not bundled in the MIT-licensed main
mod JAR.

Back up important worlds before changing any mod list.

## 中文更新说明

Blade Tetra 1.0.0 是首个功能冻结的正式版本，将 Tetra 模块化锻造完整接入
SlashBlade: Resharped。

- 模块化拔刀剑拥有刀身、刀柄、刀镡、刀鞘、鎺、柄头、刀樋和魂铭八个部件槽。
- 刀身构装决定居合、连舞与断岳三种战斗流派。
- Tetra 修理与锻造会保留重锋的所有者、击杀数、耐久、断刀、SA 与连段状态。
- 包含 512×512 动态材质、独立部件造型、预设/旗帜鞘绘、材质发光与觉醒魂铭辉光。
- 锻刀秘录记录八条隐藏传承：初心、百炼、万象、雷切、赤月、镜花水月、千本樱与 NBT 仙人。
- 可选 Contract Blade Core 联动可让觉醒赤月绑定持久存在的契约剑灵。
- 修复普通非发光模块刀在手持时每帧重建 512×512 发光图集造成的严重掉帧。
- 保留仅供开发测试的传承调试札；它没有配方、不进入创造标签页，正式环境默认禁用。
