# 拔刀剑：百构流派 1.5.8

御影留了一缕神火，但接下来的刀，还是要你自己挥。

- 调整百鬼及以上神域挑战的御影援助：不再常驻协战，而是在玩家生命值降至 30% 或以下时，召来神火环绕玩家，持续治疗并阻隔靠近的仪式敌人。神火持续 6 秒，每位玩家每场挑战只能触发一次；不能复活，也不免疫远程攻击和地面危险。
- 神域挑战保留现有难度、波次与奖励。首次通关后可获得《神域之外》，为本篇章作结，并留下后续故事的线索。
- 更新业镜各状态、无生残印和剑鬼残魂的像素贴图，让不同状态更容易辨认。
- 工作台新增部分刀装特殊效果的数值与触发条件说明，并补齐模块化拔刀剑等物品的全息球标题翻译。
- 简化御影访客对话界面，默认不再显示立绘；同时缩减安装包体积。

多人游戏请同时更新客户端和服务器至 1.5.8。
