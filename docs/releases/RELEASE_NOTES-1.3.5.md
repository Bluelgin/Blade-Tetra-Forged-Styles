# Blade Tetra 1.3.5

This update focuses on resource optimization. It does not change gameplay, balance, or the appearance of existing blades.

## Resource Optimization

- Removed unused legacy combination models left over from development.
- Retained all 108 modular blade combinations currently used by the mod.
- Reduced the mod size from approximately 10.9 MiB to 5.9 MiB, nearly a 50% reduction.
- Existing blade, scabbard, guard, and handle combinations remain unchanged.
- Handheld, sheathed, broken blade, fragment, and inventory models are unaffected.
- Existing worlds and previously crafted modular blades remain compatible.

## Additional Notes

- Tested client startup and existing world loading after the cleanup.
- This update contains no balance changes.
