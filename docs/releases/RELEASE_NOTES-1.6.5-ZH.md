# 拔刀剑：百构流派 1.6.5

## 千门剑谱：编出自己的流派

- 加入自创流派完整流程：挥刀后用式录札采录最近一次有效普通招式，最多记录六招；允许重复招式，但每次都需要实际重新出招。
- 编纂界面支持命名、选择、上移、下移、删除、撤销末招和清空；完成后获得可重复使用的 Tetra 原生卷轴。
- 在 Tetra 工作台使用剑谱，锻造短、标准或长三档自创刀身，分别调整普通近战覆盖范围与安全衔接节奏。
- 接入正式式录札贴图、纸墨编纂界面、工作台图标，以及依据真实采录、成谱结果播放的 HUD 和短动画。
- 修复自创连段可能一直停在第一招、客户端与服务器顺序不同，以及连续相同动作无法正确推进的问题。

## 离线分享：带着名字一起导入

- 加入剑谱导入、解码预览、导出与复制界面；分享码保留剑谱名称、动作顺序和重复动作。
- 改用无文字前缀的紧凑分享码。四个汉字的剑谱名搭配两招约 27 字符，六招约 32 字符；外部动作与更长名称会增加长度。
- 导入前显示动作与依赖信息，由服务器继续检查所需模组、版本和普通招式权限。分享码不能绕过动作权限或免费取得 SA。
- 不兼容开发期间未发布的旧 `BTSTYLE1:` 分享码；已有刀与卷轴的存档格式不受此次短码调整影响。

## 秘传·离锋：剑气与自创流派接轨

- 保留并完善 1.6.0hotfix 的离锋剑气表现。研习离锋秘卷后，在 SSS 下由真实普通斩击触发剑气，无需击败末影龙。
- 适配自创流派的三档刀身和重复动作；SA、无伤害装饰与单纯切换连段状态不会额外生成剑气。
- 修复剑气被普通受伤冷却吞掉的情况，保留真正的无敌、防御与伤害取消机制；剑气命中不额外击退目标。
- 连舞交叉与断岳双层外观改由同一个剑气实体绘制，减少装饰实体和客户端重复搜索。
- 新增「仅主层／均衡／完整」三档剑气画质，以及装饰距离和每帧数量限制。画质只影响可选装饰，不改变伤害、射程或攻击次数。

## 其他调整

- 御影普通挑战与回忆战暂时封印，等待战斗完善；保留旧进度及符合资格的非战斗访客入口。
- 整理项目首页、功能指南、开发记录、规划与历史文档；历次更新日志统一收纳到 `docs/releases/`。

## 安装与更新

适用于 Minecraft 1.20.1 / Forge 47.x，需要 Tetra 6.3.0–6.x、mutil 6.2.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

使用 `blade_tetra-1.6.5.jar` 替换旧版模组文件，不要同时保留两份 Blade Tetra。多人游戏请将客户端与服务器一起更新至 1.6.5；升级存档前建议备份。
