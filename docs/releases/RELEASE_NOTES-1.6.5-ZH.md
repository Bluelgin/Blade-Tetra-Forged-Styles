# 拔刀剑：百构流派 1.6.5

## 千门剑谱 · 你的流派，由你署名

师父领进门，连招自己编。

- 新增自创流派「千门剑谱」。用式录札采录普通招式，将最多六招编成自己的剑谱，支持重复招式。
- 在编纂界面命名、调整顺序、删除、撤销和清空，完成后获得可重复使用的 Tetra 剑谱卷轴。
- 提供短、标准、长三档自创刀身，在攻击覆盖与连招节奏之间选择适合自己的手感。
- 剑谱支持离线导入、预览、导出与复制。分享码会保留名称和招式顺序，把你的得意连招一起交给朋友。
- 式录札、纸墨编纂界面、工作台图标与采录反馈配套登场。剑谱有了，排面也得跟上。

## 秘传·离锋 · 自创流派也能出剑气

- 离锋支持自创流派，涵盖三档刀身与重复招式。研习后达到 SSS，普通斩击即可触发剑气。
- 优化密集剑气场景的客户端开销，保留连舞的交叉与断岳的双层外观。
- 新增「仅主层／均衡／完整」三档剑气画质，可调整装饰距离和数量。画质设置不影响伤害、射程与攻击次数。
