# 拔刀剑：百构流派 1.2.0

适用于 Minecraft 1.20.1、Forge 47.x、Tetra 6.10.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

## 本次更新

- 新增普通锻造刀身“本式刀身”，进入本传流。
- 本传流完整沿用重锋原生的地面、方向、潜行和空中攻击流程，不重排原生攻击树。
- 新增 Re:Avaritia 与 Avaritia Lite 无尽锭的可选适配，不增加硬前置依赖。
- 无尽锭可用于全部拔刀剑金属模块，拥有终局级属性、完整度收益与魔力容量。
- 无尽部件使用 Blade Tetra 原创生成的深空、星云与稀疏星光材质，并带缓存的自发光星辉。
- 刀饰采用固定在柄头的静态模型，不提供战斗属性、不消耗完整度，也不引入动态物理开销。

## 设计边界

- 无尽锭拥有有限但极高的耐久与伤害，不会绕过断刀、维修和锻造流程。
- 星空贴图按材料组合生成一次并进入有界缓存，不会逐帧重新生成。
- 本传流没有居合、连舞和断岳的特化加成，定位为均衡的完整重锋路线。
