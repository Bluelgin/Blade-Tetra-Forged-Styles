# Blade Tetra 1.3.1

## MMT material visuals

- Added automatic visual profiles for materials supplied through Tetra and
  More Material Tetra without adding MMT as a required dependency.
- Heavy, crude, polished, and ordinary metals now use visibly different
  procedural surface finishes instead of sharing one recolored metal pattern.
- Material keys and effects can now contribute restrained fire, frost,
  lightning, soul, shadow, cursed, cosmic, arcane, or toxic details.
- Special details can include a subtle emissive layer while preserving the
  material's own Tetra tint and each SlashBlade component's selected material.
- Existing hand-tuned materials such as dragonsteel, ghost ingots, cursed
  metal, and infinity ingots remain higher-priority visual profiles.

This update changes presentation only. Material attributes and special effects
remain fully owned by Tetra and their source compatibility mods.
