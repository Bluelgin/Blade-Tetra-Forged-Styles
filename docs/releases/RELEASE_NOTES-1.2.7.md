# 拔刀剑：百构流派 1.2.7

适用于 Minecraft 1.20.1、Forge 47.x、Tetra 6.3.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

## Tetra 向下兼容

- 将 Tetra 最低支持版本下调至 6.3.0；同一模组文件兼容 Tetra 6.3.0–6.x。
- 为 Tetra 6.10 新增的模块化耐久处理加入跨版本适配：Tetra 6.10+ 保留其伤害事件与 Bloodbound 处理，6.3–6.9 则沿用安全的原生耐久流程。
- 耐久附魔仍只由拔刀剑原生流程结算，不会因兼容层重复减伤，也不会增加武器 NBT。
- 已完成 Tetra 6.3.0、6.9.0、6.10.0 与 6.17.0 的编译验证，并完成最低版和当前新版的数据加载测试。

## 通用 Tetra 附属材料外观

- 模块化拔刀剑的动态外观现在会直接读取 Tetra 当前已加载材料的纹理色与材料分类。
- 附属模组提供的标准金属、宝石、骨、木与石材可自动获得相应的刀身配色、连续表面类型和刀光颜色。
- 无尽锭、龙钢、诅咒金属、暗黑金属、铁木、钢叶、骑士金属与炽铁等已有精制样式仍具有更高优先级。
- 已使用 More Material Tetra 2.2.941、Tetra 6.9.0、mutil 6.2.0 与 Curios 完成客户端实测；MMT 标准材料能够与本模组的通用外观解析共同加载。
- MMT 与 Curios 仍然只是可选模组，不是本模组的运行前置，也不会被打包进发布文件。MMT 2.2.941 自身不兼容 Tetra 6.10+，使用 MMT 时应采用 Tetra 6.9.0。
- 本模组不复制 MMT 资源，也不接管其数值、模块、图纸、饰品或特殊效果；伤害、耐久、完整度、魔力、工具需求和修理材料仍由 Tetra 及材料提供方原生决定。
- Tetra 材料数据重载会使动态外观缓存安全失效并重新生成，不增加武器 NBT，也不需要迁移旧存档。
