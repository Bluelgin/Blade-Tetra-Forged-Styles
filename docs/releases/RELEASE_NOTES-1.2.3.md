# 拔刀剑：百构流派 1.2.3

适用于 Minecraft 1.20.1、Forge 47.x、Tetra 6.10.0–6.x 与拔刀剑：重锋 1.9.63–1.x。

## 流派伤害再平衡

- 连舞流胁差刀身的材料伤害提取由 0.78 提高至 0.88，改善高速连段在实战中因目标移动或漏刀产生的刮痧感。
- 断岳流野太刀刀身的材料伤害提取由 1.30 降至 1.18。
- 断岳纵劈、横扫和破势追击倍率分别由 1.18、0.95、1.08 调整为 1.12、0.92、1.05。
- 断岳仍然保留重击、大范围、击退、破势和霸体优势，但不再同时拥有过高的单体持续伤害。
- 本次调整不改变操作、攻击范围、耐久、存档结构或武器 NBT。
