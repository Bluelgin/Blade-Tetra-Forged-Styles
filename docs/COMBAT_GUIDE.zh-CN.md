## 三分钟上手

1. 在 Tetra 工作台中查看或更换刀身。刀身决定流派，不需要额外按键切换。
2. 先在地面连续按攻击键，熟悉当前流派的基础循环。
3. 再练习潜行方向技与空中攻击。它们会暂时接管攻击，但不会永久改变流派。
4. 最后加入 SA（Slash Arts）和部件效果，形成自己的构筑。

本模组沿用《拔刀剑：重锋》的输入系统，不增加独立的“流派技能键”。下文使用默认习惯描述操作：

| 记号 | 含义 |
| --- | --- |
| `左键` | 攻击键 |
| `右键` | 使用键 |
| `前` / `后` | 相对玩家视角向前或向后移动 |
| `潜行` | 按住潜行键 |
| `停手` | 暂时不输入攻击，让动作结束或让刀归鞘 |
| `SA` | 拔刀剑的 Slash Arts，具体招式取决于刀上装配的能力 |

如果修改过按键，请以游戏内实际绑定为准。连招中的箭头表示“动作衔接”，不是要求同一游戏刻同时按下所有按键。

## 我该选哪一种流派

| 流派 | 刀身 | 战斗定位 | 上手难度 | 推荐给 |
| --- | --- | --- | --- | --- |
| 本传流 | 本式刀身 | 均衡，完整保留重锋攻击树 | ★★ | 想先学会通用操作的玩家 |
| 居合流 | 打刀刀身 | 窄范围单体爆发，讲究归鞘和时机 | ★★★ | 喜欢一击、进退和节奏感的玩家 |
| 连舞流 | 胁差刀身 | 快速多段、持续压制、机动泛用 | ★★ | 喜欢连续攻击和灵活走位的玩家 |
| 断岳流 | 野太刀刀身 | 大范围重击、击退、破势和有限霸体 | ★★ | 喜欢正面清群与重武器手感的玩家 |

不确定时，先选本传流。如果已经熟悉《拔刀剑：重锋》，可以直接按喜欢的战斗节奏选择其他流派。

## 四种流派

### 本传流：均衡与完整

**进入方式：**安装本式刀身。

本传流不获得居合、连舞或断岳的专属倍率，也不重排地面攻击。它完整沿用《拔刀剑：重锋》的地面、方向、潜行与空中攻击树，是学习基础操作和测试 SA 的最佳路线。

#### 入门打法

`地面连续攻击 → 方向技调整位置 → 空中追击或停手收势`

- 面对单个敌人时，先用普通地面连段熟悉命中节奏。
- 面对一群敌人时，用前向突进接近，或用上挑把目标带入空中。
- 想练习新的 SA 时，先用本传流确认 SA 的蓄力时间、距离和命中方式，再决定是否改成特化刀身。

#### 优点

- 招式齐全，没有需要额外记忆的流派规则。
- 单体、群体、机动和空战都能处理。
- 换装不同部件时，容易感受到部件本身带来的变化。

#### 注意事项

- “没有额外倍率”不代表弱；本传流的价值是稳定和完整。
- 如果方向技无法触发，先确认自己在地面、正在潜行，并且方向键与右键确实同时按下。

### 居合流：归鞘、拔刀与残心

**进入方式：**安装打刀刀身。

居合流的核心不是不停点击，而是让刀完成归鞘，短暂蓄势后打出高质量的第一次拔刀。拔刀判定较窄，并会锁定正面约 4.25 格内的单个目标，因此应先对准真正想斩的敌人。

#### 最简单的拔刀

`停手归鞘 → 等待约 6 tick → 听到清脆提示音 → 攻击`

完全归鞘并等待至少 6 tick 后，下一次拔刀成为蓄势拔刀。不要把归鞘声和蓄势完成声混淆：看到刀收回、再听到第二个较轻的金属提示，才是稳定出刀的时机。

当前拔刀伤害节奏为：

- 仓促拔刀：基础居合倍率 `1.60×`。
- 完全蓄势拔刀：倍率提高至 `2.20×`，并获得额外的完美居合伤害。
- 从至少 3 格外完成前向次元步，并在 12 tick 内打出蓄势拔刀：倍率提高至 `2.35×`。
- 速拔鞘会再使居合起手提高 `15%`。

这些倍率只属于拔刀起手；后续斩击负责衔接和收势，不会反复享受同一份起手爆发。

#### 安全循环

`蓄势拔刀 → 继续攻击完成后续动作 → 停手归鞘 → 再次等待提示 → 蓄势拔刀`

适合刚开始练习时使用。每轮只关注一次高质量拔刀，不要为了多点几下而错过下一轮蓄势。

#### 踏步居合

`在目标 3 格外锁定 → 前向次元步 → 落到目标近侧 → 12 tick 内蓄势拔刀`

- 成功的前向次元步会尽量把玩家校正到目标附近的安全地面并自动转向。
- 周围没有安全落点时，会保留重锋原本的落点，不会强制穿墙或把玩家塞进方块。
- 距离太近、拔刀太晚或出刀前尚未完成蓄势，都拿不到最高一档奖励。
- 无脑小连招Shift+V+左键拔刀 then  Shift+S 退场
- 无脑小连招 左键拔刀+V  （范围居合斩）

#### 残心退场

`居合拔刀命中 → 8 tick 内使用后向次元步 → 直接进入归鞘 → 重新蓄势`

这套循环把居合的进场、爆发、退场连成一体：

`前向次元步 → 蓄势拔刀 → 后向次元步 → 归鞘 → 再进场`

#### 生存能力

拔刀动作开始的前 6 tick 内，来自敌人且不绕过护甲的伤害降低 `25%`。这是短暂护身，不是无敌，也不能代替走位。

#### 常见错误

- **一直连点：**刀没有安定归鞘，自然无法完成蓄势。
- **没有对准目标：**居合是窄角度单体攻击，不适合把整群怪同时包进判定。
- **次元步后才开始等待：**踏步奖励窗口只有 12 tick，应先完成蓄势或立刻把握出刀时机。
- **把后续斩当成第二次居合：**真正的爆发集中在每轮第一次拔刀。

### 连舞流：不断连的多段压制

**进入方式：**安装胁差刀身。

连舞流使用《拔刀剑：重锋》成熟的 B 系地面连段。胁差拥有更快的攻击速度和较好的耐久利用率，代价是单次伤害较低。它依靠完整连段、持续贴身和稳定 Rank 把总伤害打出来。

#### 入门连舞

`地面连续攻击 → 保持目标在正面 → 完成整套 B 系连段 → 走位或重新起手`

普通地面左键或右键都能进入连舞起手。想稳定打出完整连舞时：

- 保持连续、均匀的输入，不必疯狂连点。
- 用鼠标持续跟随目标，避免后半段从目标身边划过。
- 敌人被击退或自己需要调整位置时，宁可重新起手，也不要对空气硬打后续段。

#### 机动连舞

`前向突进 → 地面连舞 → 上挑 → 空中连斩 → 空中下劈`

方向技和空中技会覆盖当次普通连舞输入，因此可以用来追敌、抬高目标或安全落地。回到地面后，普通攻击会重新从连舞起手开始。

#### 对单体

- 贴近目标侧面，减少被正面攻击打断的机会。
- 大型目标不容易被打出攻击范围，最适合完整连舞。
- 稳固柄能在每次有效命中时补充少量 Rank，和高频攻击很契合。

#### 对群体

- 不要站在怪群中央盲目打完整连段；先用方向技切入边缘。
- 一边横向移动一边转动视角，让多段刀光扫过不同目标。
- 被包围时优先空中脱离或重新拉开距离，不必执着于不断连。

#### 常见错误

- **只比较单击数字：**连舞的价值在多段总伤害、命中频率和机动性。
- **攻击速度过快却跟不上目标：**继续堆攻速之前，先保证自己能让后半段命中。
- **每次方向输入都夹着潜行：**这会触发通用方向技并中断当前的普通连舞路线。

### 断岳流：纵劈、横扫与破势

**进入方式：**安装野太刀刀身。

断岳流以两段地面循环为核心：

`断岳纵劈 → 宽幅横扫 → 断岳纵劈 → ……`

第一击就是威力最大的纵劈，不需要先打三段铺垫。纵劈和横扫承担不同职责，掌握它们的朝向比快速点击更重要。

#### 断岳纵劈

- 正面判定距离约 `6.25` 格，半角约 `45°`。
- 伤害倍率 `1.12×`，附带强击退。
- 命中后给目标施加持续 3 秒的“破势”。
- 动作前 11 tick 内受到的普通伤害降低 `35%`，并免疫击退。

纵劈适合对准精英敌人、怪群中心或正要发动攻击的目标。有限霸体可以让重击更不容易被打断，但仍然会受到伤害，也不能防御绕过护甲的环境伤害。

#### 宽幅横扫

- 判定距离约 `5.25` 格，半角约 `110°`，能覆盖玩家前方及两侧的大范围。
- 伤害倍率 `0.92×`，重点是清扫和衔接，而不是单体爆发。
- 横扫后再次普通攻击，会回到断岳纵劈。

#### 破势追击

纵劈命中 3 tick 后，施加者的下一次直接斩击会消耗破势并造成 `1.05×` 伤害。第二段攻击不会在破势刚附加的瞬间错误地吃掉它。

最简单的利用方法就是保持基础循环：

`纵劈施加破势 → 横扫清场并消耗破势 → 下一轮纵劈`

也可以在纵劈后根据敌人的位置，改用方向技或其他直接斩击消耗破势。

#### 输入节奏

断岳纵劈拥有较晚的有效接招帧。过早输入会被短暂缓存，但疯狂点击不会让刀更快落下。推荐看清动作：

`确认纵劈开始落下 → 输入下一击 → 横扫动作出现 → 再准备下一次纵劈`

#### 常见错误

- **把纵劈当成 360° 范围技：**它很远，但仍然要求玩家面对目标。
- **只用横扫打单体：**横扫是范围与衔接段，纵劈才是重击核心。
- **仗着霸体站桩：**35% 减伤不是免伤，残血时仍应退开。
- **狂点攻击：**重武器的命中时间轴不会因此加速。

## 所有流派都能使用的方向技

居合、连舞和断岳只替换普通地面起手。通用方向技与空中技仍沿用《拔刀剑：重锋》：

| 状态 | 输入 | 作用 |
| --- | --- | --- |
| 地面 | `潜行 + 前 + 右键` | 前向突进斩，用于接近或穿过敌阵 |
| 地面 | `潜行 + 后 + 右键` | 上挑斩，用于起手空中连段 |
| 空中 | 普通攻击 | 进入空中连斩 |
| 空中 | `潜行 + 后 + 右键` | 空中下劈，用于收尾和快速落地 |

方向技触发时，会优先于当前流派的普通地面攻击。因此连招打错时，先检查自己是否仍按着潜行或方向键。

次元步属于《拔刀剑：重锋》的移动能力。居合流会额外识别前向次元步的进场距离与后向次元步的残心退场，但不会改掉重锋原本的锁定和发动规则。

## 部件搭配

没有唯一毕业答案。先决定“想强化哪一种行为”，再选择部件。

| 部件 | 效果方向 | 适合玩法 |
| --- | --- | --- |
| 速拔鞘 | 居合起手伤害提高 `15%` | 居合流爆发构筑 |
| 灵力鞘 | 成功发动 SA 后 2 秒内，斩击伤害提高 `15%` | 高频 SA、连舞追击或通用 SA 构筑 |
| 精密鎺 | 将 SA 的精准蓄力窗口延长 2 tick | 还不熟悉精准 SA 时，或追求稳定成功率 |
| 强化鎺 | 有概率免除一次刀耐久消耗 | 连舞等高频消耗玩法 |
| 迅捷柄 | 偏攻击速度 | 连舞与重视手感的构筑 |
| 稳固柄 | 偏完整度，并在命中时补充少量 Rank | 连舞、长时间战斗 |
| 轻镡 | 提高挥刀速度 | 泛用速度构筑 |
| 护御镡 | 潜行持刀受击时消耗耐久，使普通伤害降低 `25%` | 断岳、正面作战与高容错构筑 |
| 重型柄头 | 原本不带击退的暴击斩击会挑飞目标 | 居合控制或空中追击 |
| 轻型柄头 | 提高攻速，但降低整刀完整度 | 愿意用完整度换速度的构筑 |

### 推荐起点

- **居合爆发：**打刀刀身 + 速拔鞘 + 精密鎺。
- **连舞稳定：**胁差刀身 + 稳固柄 + 强化鎺。
- **断岳容错：**野太刀刀身 + 护御镡 + 偏耐久的刀装。
- **SA 追击：**任意刀身 + 灵力鞘 + 精密鎺。

材料、打磨和附属模组提供的 Tetra 属性仍会参与最终伤害、攻速、耐久和完整度。攻略中的搭配只描述功能方向，不限制材料选择。

## 常见问题

### 为什么我的流派突然变了？

流派直接从刀身模块读取。更换打刀、本式、胁差或野太刀刀身时，连段根节点会一起改变；它不是单独保存在武器上的开关。

### 左键和右键都能开始普通连段吗？

在地面、没有满足方向技条件时，两者都可以进入当前流派的普通起手。带有潜行和方向的右键组合会优先触发方向技。

### 为什么快速点击没有立刻进入下一段？

动作具有最低接招帧，必须先经过命中时间轴。居合与断岳会缓存一次过早输入，但缓存不是无限连点；保持一次、清晰的输入更可靠。

### 为什么居合打不到旁边的怪？

这是预期设计。居合优先锁定正面窄角度内的一个目标，定位是单体爆发；清理大群敌人更适合连舞或断岳。

### 断岳霸体为什么还是会掉血？

断岳纵劈前段提供 35% 减伤和免疫击退，不提供无敌。绕过护甲的伤害和没有攻击来源的环境伤害也不受这层保护。

### SA 属于哪一种流派？

SA 由刀上装配的 Slash Arts 决定，四种流派都可以使用。流派改变普通攻击路线，部件则可以强化精准 SA 或 SA 后的追击。

### 特殊刀会不会改变基础连招？

镜花水月、千本樱等隐藏传承会在对应流派之上增加能力，但基础流派仍由当前刀身决定。为了保留探索体验，本页不展开解锁谜题；完整条件请查看[特殊刀与隐藏传承解锁 Wiki](legacy-wiki/README.md)。
