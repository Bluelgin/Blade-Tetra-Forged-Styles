# 全息球显示：暂缓扩展

本次自定义部件统计已按用户决定回退，后续有明确方案时再完善。

## 保留

- 模块化拔刀剑、锻造术式珠的全息球标题翻译，以及已补齐的中文界面标签。
- Tetra 原生全息球统计和第三方附属自己注册的统计栏。
- 工作台原生整刀改装前后对比。
- 工作台中的六种条件效果说明：速拔鞘、精密刀镞、灵蕴鞘、护手刀锷、稳固刀柄、重型柄头。

## 撤回

- 全息球部件专用属性栏和对应翻译。
- 详情页槽位上下文、反射探测，以及两项可选客户端 Mixin。
- 按统计栏类名隐藏 Tetra 栏目的过滤逻辑。该逻辑会误隐藏使用通用 GuiStatBar 的第三方效果栏，例如 MMT。

## 后续方向

如果重新推进，应仅精确替换明确识别的基础属性栏，保留第三方效果栏，并分别核对整刀数值、部件贡献与条件效果。不能用统计栏的 Java 类所属包判断其注册来源。
