# 名刀映锻：通用刀装研习

附属自动识别、已验证版本、限制项与玩家测试流程见 [ADDON_COMPATIBILITY.md](ADDON_COMPATIBILITY.md)。

## 当前方案：整套镡柄

- 玩家只仿造两个部分：独立刀鞘、完整镡柄刀装。镡槽控制整套镡柄外观，柄芯材料和既有工艺不替换。
- 优先直接读取源 OBJ 的完整 handle 组；无独立 handle 组时，只在刀身与整套刀装之间切一次，不切开刀镡与刀柄。
- 镡柄共用安装变换、保持整体比例，不允许不同来源的镡柄交叉拼装。
- 刀鞘恢复分体尺寸改动前的定位方式：保留模型 Y/Z 原点，非狐系沿用旧的长度统一缩放，黑白狐沿用旧原点定位。不再使用新增的粗细独立缩放和截面居中。
- 玩家侧高级模式入口关闭，研习只保留小游戏。新研习自动使用模型默认分区；旧校准与独立柄改进数据保留，不删除、不再驱动外观。
- 新刀谱只解锁鞘和镡柄；旧黑白狐独立柄配方禁用，改进定义保留供旧存档读取。
- 同源鞘与整套镡柄仍只触发一次原有 +0.25 攻击加成；没有新增 SA 或其他属性加成。
- 模型几何验证不能替代手持、入鞘和挂刀台的视觉验收，仍需游戏内截图确认。

验证：整套刀装流程在 Tetra 6.3.0、6.9.0 + MMT 的隔离测试服分别完成 30 次锻造。另检查了柄芯材料不变、旧柄记录继续可读但不单独生效，以及历史校准记录不被自动删除。28 项单元测试覆盖 8 种源模型及存档/通信数据。

旧的分体仿造、高级校准与尺寸微调记录已移至[历史方案](../history/NAMED_BLADE_IMPRINTING_LEGACY.md)，不作为当前操作说明。
