# 名刀锭与模块化锻造

## 新的获取方式
把一把完好的原版／附属拔刀剑置于 3×3 工作台中心，四周放置 8 个 **破碎的耀魂**（`slashblade:proudsoul_tiny`），获得对应的 **名刀锭**。

- 原刀返还，按其最大耐久消耗约 10%（向上取整，最少 1 点）。
- 当剩余耐久不足以安全提取时，配方不可用；不会自动折断或吞掉原刀。
- 一次制作 1 枚名刀锭；同一把原刀可在修复后再次提取。
- 名刀锭采用一个通用物品 ID `blade_tetra:named_blade_ingot`，NBT 保存来源名刀；不存在上百个静态锭注册物品。
- 无铭刀「木偶」作为本体基础刀提供显式来源适配。
- 不再新合成／展示旧映锻研习卷轴和研习小游戏入口；旧物品和已存档的刀装记录仍可读。

## 来源资格判断与模型提示

- 物品栏提示和 3×3 合成使用同一个 `NamedBladeIngotEligibility.inspect` 入口；内部复用原有 `LegacyResearchability.inspect` 识别名刀与断刀状态，外加剩余耐久检查，不再另写一套名刀目录/识别流程。
- **可映锻外观**：客户端继续使用原有 `LegacyResearchabilityClient` 检测独立刀鞘/刀身/镡柄边界。通过时显示「名刀锭刀装支持此刀模型」，可提取时另行显示「可提取名刀锭」，不再提示研习或映录。
- **元数据可识别、模型无法完整解析**：允许在服务端提取代表该来源的名刀锭，但在物品栏明确提示「此刀模型暂不支持完整适配，名刀刀装将回退为普通模型」；绝不能误显示「此刀形制可被映录」。
- **耐久不足**：即使模型可识别，也会提示修复后才能提取，而合成配方会拒绝执行。
- 服务端只查询 SlashBlade 状态与来源目录元数据；OBJ 几何是否可安全复用属于客户端美术能力，不接受不可信的客户端“允许合成”回报，不在专服进行渲染模型解析。这样每种提示都与实际允许的操作一致。

## Tetra 工作台的三个专属部位

| Tetra 槽 | 名刀锭 | 行为 |
| --- | --- | --- |
| `slashblade/blade` | 是 | 新的名刀刀身模块，尝试引用原刀 OBJ 的刀身分组与纹理 |
| `slashblade/saya` | 是 | 原有名刀刀鞘模块和适配机制 |
| `slashblade/tsuba` | 是 | 原有完整镡柄一体模型，不再拆分 |
| `slashblade/tsuka` | 否 | 保留原刀柄材料、工艺及原有强化 |
| 其他改装槽 | 否 | 与名刀锭无关 |

对应 Tetra schematic 分别是 `slashblade/legacy_ingot_blade`、
`slashblade/legacy_ingot_saya`、`slashblade/legacy_ingot_tsuba`。
只消耗实际放入工作台的名刀锭，**由锭上的来源身份决定最终刀型**，而不是由玩家选择显示的名字或客户端贴图决定。

当前传统「正传」判定仍采用同源刀鞘 + 完整镡柄；单独替换刀身不伪造正传／异传效果。老异传组合与它们的专属 SA/SE 不修改。

## 动态名刀锭美术

客户端保留铁锭的轮廓、银白亮边与金属明暗，将原刀物品图标的背板／大纹样取样区域连续映射到锭内部。顶面与侧面沿用铁锭的明暗，保持来源纹样的方向，不再四象限旋转拼接或大范围模糊。输出为 32×32 清晰像素贴图。

- 优先使用资源包显式指定的背板贴图／UV 区域；未指定时，从原刀 OBJ 的 `backplate`／`item_blade` 分组中选择较宽、较完整的 UV 面作为启发式取样。后者不保证每个第三方模型都能识别到背板，需要实机审阅，可用显式配置纠正。
- 没有可靠区域时使用来源主纹理；缺失或损坏资源回退普通铁锭。透明区域使用所选区域的非透明平均色补齐。
- 资源包可提供 `assets/blade_tetra/named_ingot_visuals/<来源命名空间>/<来源路径>.json`，格式例如 `{"texture":"example:textures/item/backplate.png","region":[0,0,1,1]}`。`texture` 和 `region` 均可省略，区域采用左上原点的归一化图片 UV；显式纹理未指定区域时取整图。错误配置回退自动取样。
- 全息球无来源通用锭继续使用原来的黑芯红问号贴图，不受此生成流程影响。
- 最多缓存 96 个来源图标，资源重载释放 GPU 缓存并重新读取取样配置；服务器不解码图片、不分析 OBJ。
- `./gradlew runClient -PnamedIngotArtReview` 在独立 `build/named-ingot-art-review` 目录创建临时创造世界，打开真正的「名刀锭」独立创造标签页，保存 `named-ingot-creative.png` 后退出。它不重建界面、不打开玩家存档。页面内仅展示有来源的名刀锭，问号锭只用作标签图标；原 BladeTetra 主标签页不再重复展示名刀锭。排序以拔刀剑本体优先，其余按来源模组及来源路径稳定排列；标签声明排在主标签之后，分页位置由 Forge 决定。

## 兼容与验收

保留旧刀装的必要读取定义、来源软引用与普通 Tetra 强化；旧卷轴对应的制作入口保持停用。新增刀身有独立来源；镡柄模型绝不二次切割。移除附属时记录保留，无法绘制的部件回退普通模型，重新安装同来源可恢复。

**验收重点：** 3×3 配方与损耗耐久、三种部件锻造、刀柄材料不变、完整镡柄模型、跨附属来源混搭、手持／入鞘／挂刀台／物品栏、资源重载及移除附属。自动构建或 smoke 不能代替美术实机验证。

## 旧映锻退役与历史物品

- 空白映锻卷继续注册为 `blade_tetra:legacy_imprint_scroll`，名称改为「消失的知识」，悬停文字为「纸已残，旧法亦无人再识。」和「你感觉自己忘记了什么，可怎么也想不起来。」。
- 它没有研习或右键功能，不加入创造物品栏，不提供配方或正常产出；管理员仍可通过命令获取。
- 已有物品通过原注册 ID 自然加载，不扫描世界、不清除物品、不改写历史物品 NBT。
- 已完成的 Tetra 名刀刀谱保持原物品、名称、外观与 NBT；仅停用对应旧映锻配方和产出。不添加逐卷轴禁用逻辑，不影响其他 Tetra 卷轴及原生展示行为。
- 名刀来源识别、模型适配、属性快照、正传／异传及旧武器所需兼容逻辑继续保留。
- 「消失的知识」使用破碎纸张贴图：SVG 母版为 `art-previews/lost_knowledge.svg`，以 32×32、透明背景导出到 `assets/blade_tetra/textures/item/legacy_imprint_scroll.png`，沿用原物品模型引用。暖色残纸、断开的刀形墨迹与朱砂残印与已确认预览一致。
- 可使用 CairoSVG 重新导出：`cairosvg art-previews/lost_knowledge.svg -o src/main/resources/assets/blade_tetra/textures/item/legacy_imprint_scroll.png -s 0.0625`。SVG 标称大小为 512×512，缩放后严格落在 32×32 像素网格；CairoSVG 仅为美术导出工具，不是模组运行依赖。

## 附属美术验收环境

独立创造页截图环境可启用现有 `-PsjapTest -PyakumoTest` 配置，安装 SJAP 1.2.16（CurseForge 文件 7039817）与 YakumoBlade 1.1.4（文件 7264677）。CI 从作者的 CurseForge 官方 CDN 获取 Yakumo JAR，放入仅供开发使用的 `run/test-libs`，复用 ForgeGradle 的反混淆依赖加载；不打包进发行 JAR，不新增玩家必装依赖。

超过 45 种来源时，验收入口通过原生滚轮操作截取列表顶部、中段、底部，分别保存 `named-ingot-creative.png`、`named-ingot-creative-1.png`、`named-ingot-creative-2.png`；客户端日志记录实际识别的来源总数与命名空间分布。截图成功仅代表该组合能够启动并呈现图标，不替代第三方武器玩法的完整兼容验收。
