# 名刀映锻：名刀锭与模块化仿造（新版）

## 新的获取方式
把一把完好的原版／附属拔刀剑置于 3×3 工作台中心，四周放置 8 个 **破碎的耀魂**（`slashblade:proudsoul_tiny`），获得对应的 **名刀锭**。

- 原刀返还，按其最大耐久消耗约 10%（向上取整，最少 1 点）。
- 当剩余耐久不足以安全提取时，配方不可用；不会自动折断或吞掉原刀。
- 一次制作 1 枚名刀锭；同一把原刀可在修复后再次提取。
- 名刀锭采用一个通用物品 ID `blade_tetra:named_blade_ingot`，NBT 保存来源名刀；不存在上百个静态锭注册物品。
- 无铭刀「木偶」作为本体基础刀提供显式来源适配。
- 不再新合成／展示旧映锻研习卷轴和研习小游戏入口；旧物品和已存档的刀装记录仍可读。

## Tetra 工作台的三个专属部位

| Tetra 槽 | 名刀锭 | 行为 |
| --- | --- | --- |
| `slashblade/blade` | 是 | 新的名刀刀身模块，尝试引用原刀 OBJ 的刀身分组与纹理 |
| `slashblade/saya` | 是 | 原有名刀刀鞘模块和适配机制 |
| `slashblade/tsuba` | 是 | 原有完整镡柄一体模型，不再拆分 |
| `slashblade/tsuka` | 否 | 保留原刀柄材料、工艺及原有强化 |
| 其他改装槽 | 否 | 与名刀锭无关 |

对应 Tetra schematic 分别是 `slashblade/legacy_ingot_blade`、
`slashblade/legacy_ingot_saya`、`slashblade/legacy_ingot_tsuba`。
只消耗实际放入工作台的名刀锭，**由锭上的来源身份决定最终刀型**，而不是由玩家选择显示的名字或客户端贴图决定。

当前传统「正传」判定仍采用同源刀鞘 + 完整镡柄；单独替换刀身不伪造正传／异传效果。老异传组合与它们的专属 SA/SE 不修改。

## 动态名刀锭美术

客户端借用原版铁锭的透明轮廓与金属亮边，填充区读取来源名刀在其定义中声明的贴图（原刀颜色／背板），按多个方位重排贴图块，并进行局部模糊混色。

- 铁锭边缘保留银白金属质感，内部为对应刀纹理的模糊彩色碎片。
- GUI、第一人称及地面显示使用来源 ID 对应的动态图标，不需每把名刀打包独立 PNG。
- 动态纹理最多缓存 96 个，资源重载释放 GPU 缓存；缺失／损坏的附属贴图回退为普通铁锭。
- 服务器完全不解码图片；名刀的服务器判定只解析来源元数据。
- 原刀没有独立的“背板”贴图时，使用其声明的主纹理进行填充，不凭空生成未提供的模型数据。

## 兼容与验收

保留 1.5.x/2.x 的旧刀装 NBT、按来源软引用、旧卷轴 schematic 与普通 Tetra 强化。新增刀身有独立来源；镡柄模型绝不二次切割。移除附属时记录保留，无法绘制的部件回退普通模型，重新安装同来源可恢复。

**验收重点：** 3×3 配方与损耗耐久、三种部件锻造、刀柄材料不变、完整镡柄模型、跨附属来源混搭、手持／入鞘／挂刀台／物品栏、资源重载及移除附属。自动构建或 smoke 不能代替美术实机验证。
