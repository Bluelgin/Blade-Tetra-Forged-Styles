# 自定义 SA：魂核与工具门槛

## 制作门槛

主、副术式均使用 Tetra 原生 outcome.requiredTools.hammer_dig：

| 术式 | 工具档位 |
| --- | --- |
| 幻影刃纵、幻影刃横、波刀龙胆 | minecraft:iron |
| 円刃、平突 | minecraft:diamond |
| 次元斩、终焉樱、虚无刀界 | minecraft:netherite |

这是制作要求，不是释放要求；已制作的旧魂珠和已铭刻的刀不作废。
维持现有耀魂材料成本，不恢复旧修饰符。

## 魂核

从当前 Tetra MaterialStore 读取魂核对应 MaterialData.primary：

```
bonus = clamp((primary - 2) * 0.025, 0, 0.15)
primaryScale = 0.85 * (1 + bonus)
secondaryScale = 0.65 * (1 + bonus)
```

primary 是 Tetra 材料主属性，不是整把刀面板或玩家最终攻击力。
MMT/数据包修改后的有效材料数据参与计算；缺失、非有限数据回退为零加成。
不增加普通攻击面板，不加额外伤害事件。

释放时将 bonus 保存到本次 PendingCast；生成的原生攻击实体保留对应阶段的
最终伤害系数，命中时只应用一次。更换核心或重载数据不改变已发射实体的系数。
最高主段系数 97.75%、副段系数 74.75%，仍沿用原生术式各自的命中机制。

刀的铭刻继续保存紧凑的核心身份，不复制材料数据，也不升级 NBT 版本。
旧版本 1/2 铭刻都能读；新释放采用当前材料规则。

## 展示与兼容

- ForgedSlashArtCore 是 tooltip、GUI 和战斗系数的唯一计算来源。
- 只装魂核的未完成魂珠也显示加成；主、副段系数是完成后的理论倍率。
- 工作台与全息球使用各自的 GuiStatBar 实例，支持原生更换材料前后比较。
- 百分比按整个术式计算，不参与 Tetra 的单槽加法贡献减算。
- 工作台用 100px 条，全息球用 60px 条，匹配两种原生布局。
- 仅客户端注册 GUI，专用服务器不加载客户端 GUI 类。
- 使用 6.3、6.9、6.12、6.17 均保留的 MaterialData.primary、MaterialStore、
  addBar 与基础 GuiStatBar 构造签名；不调用新版扩展模型或条件构造接口。
- 实际构建验证与游戏内验收应分开记录，编译通过不等于所有版本均完成实机验收。

## 验收

1. 生存模式下低级锤不能锻造高档主/副术式；升级后可制作。创造模式可能绕过工具限制。
2. 只装铁魂核、再预览钻石魂核：原生材料数据下加成从 7.5% 变为 10%。
3. 钻石魂核系数：主段 93.5%、副段 71.5%；实际伤害仍受目标护甲等影响。
4. 工作台与全息球均能比较材料；别的模块化武器不显示魂珠专用三项。
5. 旧魂珠与旧铭刻正常；魂珠后续编辑不改变已经铭刻的刀。
6. 延迟幻影剑命中、释放中换刀、多人不同魂核施放：系数按各自释放记录计算。
7. MMT 高属性材料封顶 15%；/reload 后的新释放和预览采用新数据。
