# 刀匠手册与异传确认

Patchouli 是可选依赖。安装时，主创造标签页提供「刀匠手册」，书与铁粒无序合成；未安装时配方通过 Forge 加载条件跳过。使用 Patchouli 原生书、目录、文本、聚焦及合成页面，没有独立备用界面或 Java API 依赖。

## 阅读与进度

- 六类内容：执刀与锻造、流派与剑谱、名刀与异传、刀魂与线索、刀装与外观、疑难与兼容。
- 中英文各 56 条目。面向已经熟悉 Tetra 与 SlashBlade 的玩家，讲解本模组的转换、八部位、工艺、流派、自创剑谱、离锋、名刀锭、异传、自铸 SA、觉醒魂与装饰。专属异传的能力介绍对照现有调和定义，配方展示引用真实配方。
- 线索条目由隐藏的 `blade_tetra:manual/*` 进度桥接原 `SmithingLore`，登录与在线定期补齐旧存档。原玩家 NBT 是线索发现依据，完成状态沿用已有传承进度。新线索会立即同步。
- 刀魂实用说明由原有觉醒进度、获得对应遗物或持有已觉醒武器解锁；主背包和副手均检查。技能阅读与原仪式进度分离，不替玩家完成觉醒。未发现线索者只能阅读公开引子；发现后阅读旧札，完成后展开明确仪式条件。Patchouli 自身允许用户配置关闭进度锁，因此这里是阅读节奏，不是服务端秘密保护。
- 原锻刀秘录、名刀映录和魂铭遗物保持物品 ID、阅读方式、赠书与奖励逻辑。名刀映录也说明手动融合规则；移除 Patchouli 不改变玩法进度。
- 不展示御影相关未开放内容。名刀刀身独立继承来源登记的 SE，同源鞘镡可继承来源登记的 SA。

## Alt 信息

流派名称与定位、当前刀魂及沉睡/流派限制、简短操作条件、已掌握剑技与传承、各部位来源、异传状态、导电与鞘绘信息保留。移出大段教学与数值解释，移除重复的原生 SA/SE 列表和速度效率教学；不增加「详见手册」提示。不装 Patchouli 也使用同一份简洁布局。

## 通用异传

- `ProgrammaticFusionPlan.candidate` 只发现组合；`from(ItemStack)` 只返回已经确认且当前来源匹配的组合。能力同步、实际释放、延迟应式与名称展示都走后者。
- Tetra 原生刀身操作「融合 SA」无需额外材料或新工具门槛。预览修改副本，确认结果写入有序来源对。预览物品展示实际融合 SA 名称。
- 已融合的相同来源对不重复出现操作。改变任一来源使确认失效，恢复旧来源也不会自动恢复已清除的确认。同来源重建保留确认。
- 专门设计的异传仍走原有条件与改良；通用方案不绕过它们。正传继承不变。
- 旧武器只在保存的结构能力所有者与当前组合一致、且实际 SA 为通用融合时兼容为已确认。单纯满足搭配条件不会迁移为已融合。版本标记防止新物品以后被错误当作旧武器迁移。

## 美术与验证

封面使用已确认的手绘 SVG 像素稿，导出为透明 32×32 PNG，通过 Patchouli 的自定义物品模型接入。SVG 母版为 `art-previews/bladecraft_manual.svg`，贴图为 `assets/blade_tetra/textures/item/bladecraft_manual.png`。不依赖生图模型；书内页面继续使用 Patchouli 默认界面。

`-PpatchouliTest` 仅给开发运行添加 Patchouli 1.20.1-84.1-FORGE。既有创造栏客户端验收增加原生手册编译、六分类、条目完整度、创造栏和配方检查。既有名刀锭服务端验收增加融合预览不污染输入、确认、保存重载、换来源失效、旧活动融合迁移、专属组合优先与可选配方条件检查。不以这些检查替代远程多人或所有第三方战斗兼容验收。


## 教程重排与图文验收

- 语气参考植物魔法、新生魔艺和神化的操作型手册，并阅读官方 Goety: Revelation 2.3.5 JAR 内中文手册，借鉴见闻式导入与实用说明衔接。正文、SVG 与排版均自行编写，不复制其他模组资源或长段文本。
- 预设玩家已懂前置模组。明确校正旧稿的三个入口：千门剑谱展开为复杂卷轴后放在工作台正上方；宝珠在工作台编辑、双手持物使用刻入；鞘绘/旗帜与刀直接合成，柄卷改色使用有色地毯，线恢复默认色。
- 以真实配方页、物品展示和相关篇章链接组织阅读。四种薄 JSON 模板仅使用 Patchouli 原生 item/image/text 组件，展示木偶入锻、八部位、提取实例和融合位置。动态提取图明确标为木偶示例，原刀仍返还；不伪造普通静态合成配方。
- 两张结构图的 SVG 母版位于 `art-previews/manual-pages/`，PNG 仅是其导出。手册封面沿用已确认的 SVG 像素稿。
- `-PnamedIngotArtReview -PmanualArtReview -PpatchouliTest` 共用现有隔离创造世界。先核对共享进度和封面，再打开真实 Patchouli 目录与每个中英文条目的每一跨页，检查字体是否自动缩小，截取代表页面。验收世界在截图阶段授予进度以展示后期页面，不把它当作仪式自然完成的证据。
- 截图保存为 `manual-zh_cn-*.png` 和一张英文转换页。只有 `MANUAL_ART_REVIEW_PASS` 才表示双语原生页面遍历与截图步骤通过。

## 入门配方收口

内置生存入口统一为木偶与三格铁锭合成铁打刀，再到 Tetra 工作台改装。名刀来源通过名刀锭装入刀身、刀鞘与刀镡。撤下 `blade_tetra:modular_slashblade` 配方资源，不再提供任意原刀与 Tetra 剑的内置转换路线；手册与示意图同步改为木偶入门和名刀锭后续改装。旧配方序列化器暂留兼容，旧武器的物品注册、部件迁移与存档读取不变，不扫描或重置已有武器。
