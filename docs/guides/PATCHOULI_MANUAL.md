# 刀匠手册与异传确认

Patchouli 是可选依赖。安装时，主创造标签页提供「刀匠手册」，书与铁粒无序合成；未安装时配方通过 Forge 加载条件跳过。使用 Patchouli 原生书、目录、文本、聚焦及合成页面，没有独立备用界面或 Java API 依赖。

## 阅读与进度

- 六类内容：执刀与锻造、流派与剑谱、名刀与异传、刀魂与线索、刀装与外观、疑难与兼容。
- 中英文各 38 条目。具体异传介绍复用现有本地化的调和说明；刀魂操作与代价复用遗物说明键。
- 线索条目由隐藏的 `blade_tetra:manual/*` 进度桥接原 `SmithingLore`，登录与在线定期补齐旧存档。原玩家 NBT 是线索发现依据，完成状态沿用已有传承进度。新线索会立即同步。
- 刀魂实用说明由对应原有觉醒进度解锁。未发现者只能阅读公开引子，不直接获得仪式答案。Patchouli 自身允许用户配置关闭进度锁，因此这里是阅读节奏，不是服务端秘密保护。
- 原锻刀秘录、名刀映录和魂铭遗物保持物品 ID、阅读方式、赠书与奖励逻辑。名刀映录也说明手动融合规则；移除 Patchouli 不改变玩法进度。
- 不展示御影相关未开放内容。刀身独立 SE 继承仍待单独修复，手册明确记录当前边界。

## Alt 信息

流派名称与定位、当前刀魂及沉睡/流派限制、简短操作条件、已掌握剑技与传承、各部位来源、异传状态、导电与鞘绘信息保留。移出大段教学与数值解释，移除重复的原生 SA/SE 列表和速度效率教学；不增加「详见手册」提示。不装 Patchouli 也使用同一份简洁布局。

## 通用异传

- `ProgrammaticFusionPlan.candidate` 只发现组合；`from(ItemStack)` 只返回已经确认且当前来源匹配的组合。能力同步、实际释放、延迟应式与名称展示都走后者。
- Tetra 原生刀身操作「融合 SA」无需额外材料或新工具门槛。预览修改副本，确认结果写入有序来源对。预览物品展示实际融合 SA 名称。
- 已融合的相同来源对不重复出现操作。改变任一来源使确认失效，恢复旧来源也不会自动恢复已清除的确认。同来源重建保留确认。
- 专门设计的异传仍走原有条件与改良；通用方案不绕过它们。正传继承不变。
- 旧武器只在保存的结构能力所有者与当前组合一致、且实际 SA 为通用融合时兼容为已确认。单纯满足搭配条件不会迁移为已融合。版本标记防止新物品以后被错误当作旧武器迁移。

## 美术与验证

封面使用已确认的手绘 SVG 像素稿，导出为透明 32×32 PNG，通过 Patchouli 的自定义物品模型接入。SVG 母版为 `art-previews/bladecraft_manual.svg`，贴图为 `assets/blade_tetra/textures/item/bladecraft_manual.png`。不依赖生图模型；书内页面继续使用 Patchouli 默认界面。

`-PpatchouliTest` 仅给开发运行添加 Patchouli 1.20.1-84.1-FORGE。既有创造栏客户端验收增加原生手册编译、六分类、条目完整度、创造栏和配方检查。既有名刀锭服务端验收增加融合预览不污染输入、确认、保存重载、换来源失效、旧活动融合迁移、专属组合优先与可选配方条件检查。不以这些检查替代远程多人或所有第三方战斗兼容验收。
