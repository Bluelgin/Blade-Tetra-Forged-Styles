# 御影：反应式选招与原生攻击

御影全部战斗技能现在运行在独立的 `SkillExecution` 和 `CastScope` 中。旧技能池、纯视觉补伤害时间线、剑轮反伤、三印解谜、鸟居交剪/囚笼、SA 隐藏减伤、强制解锁与删除玩家次元斩的服务端引擎已移除。战后访客、奖励、回忆战、阶段台词与既有剧情保持原有接口。

## 架构与伤害边界

- `MikageEntity` 仅保留实体身份、属性、同步动作和生命周期入口。`MikageEncounter` 管理开场、阶段、目标、执行器与剧情桥。
- `MikagePlayerObserver` / `PlayerBehaviorMemory` 记录各参战者已经发生的移动、出刀、格挡、滞空与 SA。导演按距离、行为证据、最近释放和 `MikageFollowups` 的条件边选择下一招。它不会预知玩家的下一次输入或提前取消当前招式。
- `MikageSkillSelection` 只提供已改写的技能。每只御影拥有独立 `SkillPacing`：一次大技能后至少释放两个短攻击，各大技能另有独立冷却。完成前台释放后才作下一次选择。
- `MikageNativeAttacks` 使用本体 `AttackManager`、`Drive`、`WaveEdge`、`SakuraEnd`、`JudgementCut`；回廊通过注册的 B1–B7 状态机、原生 combo 时钟和 tickAction 出刀。
- `MikageNativeCombat` 只在原生命中之前授权参战目标、检查振刀与接触资格，并把原生实体及衍生实体归属到本次 scope。原生攻击负责目标盒、飞行、碰撞、攻击回调、附魔和 `hurt`。
- `MikageNativeDamageEvents` 调整已发生的原生 `LivingHurtEvent` 金额，应用试炼单次伤害上限与自适应校准；不调第二次 `hurt`、不写玩家生命、不按 VFX 定时补伤害、不换成穿甲/魔法保底伤害。保留玩家护甲、吸收、伤害事件取消及无敌帧。
- 近战/次元斩在原生 TargetSelector 返回目标前过滤；Drive 和幻影剑用本体 ProjectileUtil 的扫掠盒与射线，先过滤非参战者，再允许原生碰撞回调。非参战玩家不会吸收一发本应射向参战者的剑。
- 原生 `forceHit` / `resetHit` 仅在御影已授权的调用中被阻止擦除无敌帧。普通玩家和其他实体的原生攻击保持默认行为。试炼幻影剑仍调用 `super.onHitEntity`，但不附带本体默认药水/眩晕，避免锁死玩家移动。
- 本体 `ArrowReflector.doReflect` 改变剑的飞行速度；其原实现不换 owner，因此反弹标记单独隔离后续对玩家的命中。返刃反弹回御影时产生破绽，普通反弹剑不伤同队玩家。
- 技能取消、目标失效、转阶段、击败或异常都会关闭 scope，清除本次全部原生攻击、假身、核心和演出，并恢复动作/重力/隐身/碰撞。千门每轮只清当前攻击，保留同一 scope 的一个清理回调，不因无限追斩累积回调。

## 短攻击池

时间单位为服务器 tick。方向/落点在前摇末尾锁定，玩家改变行动可以使攻击落空；没有视觉结束后再补命中的旧时间线。

| 新动作 | 原技能来源 | 行为与反制 |
|---|---|---|
| COMBO | 连击 | 10 tick 前摇，三次原生刀术，近身接招后恢复；可振刀 |
| IAIDO | 踏步居合 | 16 tick 前摇，最后八拍沿可见固定方向短步接近，原生横拔；可侧移、振刀 |
| CIRCLE | 环斩 | 14 tick 前摇，原生间接旋斩覆盖身侧；可离开接触范围、振刀 |
| CLEAVE | 断岳 | 二阶段起，22 tick 重举预警后原生重斩，长恢复；可侧移、振刀 |
| SAKURA | 樱落 | 二阶段起，短两刀后原生 SakuraEnd 收尾；可振刀断招 |
| DUEL | 镜返 | 可见锁路短冲，两次相斩，停止导航与继续追踪；可绕路、振刀 |
| ZANSHIN | 后台残心反制 | 二阶段起，观察已发生的移动方向，预告预计回切位置，锁定后出原生回斩；停止/改变原路线可避开 |
| FAN | Drive 扇斩 | 22 tick 预备后真正以 -18°、0°、18° 发出三条本体 Drive，伤害取自飞行碰撞 |
| WAVE | WaveEdge | 18 tick 前摇的原生窄波族，与扇形分开选择，侧移离开轨迹 |
| CUT | 次元斩 | 二阶段锁定并预告单个落点，原生 JudgementCut 命中该位置附近；移动离开 |
| SUPER_CUT | 超次元斩 | 三阶段替代普通次元斩，提前标记三个落点，间隔 12 tick 依次引爆 |
| VOLLEY | 幻剑齐射 | 两轮本体幻影剑飞行，原生普攻反弹有效 |
| RAIN | 空中剑雨 | 可见升空，九个固定落点提前显示，三排下落幻影剑；反弹/离开落点 |
| CHASE_RAIN | 逐影剑雨 | 三次有限追击，各次重新预告后锁点，最后一把金色返刃可原生反弹，命中御影给 35 tick 破绽 |

普通短刀术被振刀会取消后续出刀并给至少 20 tick 输出窗；普通失衡累计仍共用五次振刀机制。取消、失衡结束和技能恢复都不自动闪走。短刀术会完成常态距离机制要求的近身交锋。

| 千门回廊 | 三次幻剑骑行穿门，注册 B1–B7 控制出刀；接触必须来自本体原生攻击。一次新鲜振刀即可击落整次技能，落地给 40 tick 硬直并记普通失衡一次；累计五次给完整失衡 | 480 |
| 巨门剑潮 | 鸟居由竖线展开，30 tick 蓄剑后连续发射可反弹的本体幻影剑。玩家到门心以三次独立近身剑输入击破原生次元斩资源核心，收门后给 60 tick 破绽 | 720 |
| 月影真假身 | 两个无害假身与真身。真身有拔刀声、金色刀鞘闪光；近身剑击打断蓄力或振刀给 28 tick 破绽；假身只破碎，没有惩罚伤害 | 300 |

巨门仍是无限压场直到破核或合法取消：最多 64 把活剑，每把寿命 80 tick，活集合与清理回调有界；主目标离场可转移扫射目标，多人共用核心进度，各人的输入与保护独立。其他锁定技能目标离场会取消，而不会悄悄换人出刀。

## 常态间距、格挡与剧情

常态距离保持沿用 6–8 格、最多连续两次后撤后主动近身接招的机制。路线检查场地、支撑、区块、障碍、液体与玩家占位。前台技能和破防输出窗独占移动，常态脚步不抢走恢复。

格挡/振刀参考作者另一个模组 `Bluelgin/Contract-Blade` 的黑狐实现（MIT 声明保留在仓库许可证目录）。御影三个阶段空闲时都可接正面直接剑击并反击；开场/阶段保护/前台技能/失衡期间不能插入此反击。三 tick 新鲜剑输入、朝向与独立输入消费继续由 `DuelDefenseState` 管理。

`MikageStoryBridge`、ChallengeSession、访客选项、奖励与完整战后流程保持原接口；`BOUNDARY_SLASH` 仍在界闪开始时播放。仅调整战斗 HUD 提示以对应新规则，未改剧情文本或对话内容。旧视觉包与已注册的旧幻剑实体保留客户端/世界兼容，旧剑轮/朱印实体在服务端不再运行技能。

## 验证

- 六组无 Minecraft 依赖的运行时场景：261 条断言，覆盖观察、导演、清理、格挡、追斩、回廊、鸟居和常态间距。
- 新增 JUnit：完整动作池时序、独立冷却/大技能间隔、原生回调中关闭当前技能、依赖字节码调用 `hurt` 的契约、禁止视觉补伤害和直接生命写入。
- `./gradlew build`：完整 Forge 编译、资源校验、JUnit、reobfJar。
- `./gradlew runServer -PmikageNativeSmoke`：隔离 Forge/Mixin 服务端，真实 ServerPlayer（仅复用 FakePlayer 的测试连接） 验证原生近战、Drive、幻影剑、次元斩、非参战隔离、无敌帧、原生反弹、三 tick 振刀和 scope 回收。诊断通过输出 `MIKAGE_NATIVE_SMOKE_PASS`。只在显式诊断属性开启时运行；普通游戏不会创建测试会话或改世界。
- CI 在 PR 上运行完整构建和该真实服务端诊断。声音辨位、动画观感、地形实战与多人连打手感仍需要进游戏检查；服务端诊断不能替代这些体验测试。
