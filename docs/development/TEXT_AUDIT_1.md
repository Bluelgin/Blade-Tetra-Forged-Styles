# Blade Tetra 文本审计 1.0

审计基线为 `main` 的 `590a3c8`，源码版本为 `1.6.6hotfix`。CurseForge 已公开同版本 [JAR](https://www.curseforge.com/minecraft/mc-mods/blade-tetra-forged-styles/files/9492547)。GitHub Releases 的 latest 标签为 `v1.5.9`。仓库未找到 Modrinth 发布稿，按项目名称查询也未找到可确认的 Modrinth 发布页。#68 咸鱼一文字与 #69 木本传均为开放 PR，以下玩法和发布文案按本次基线编写。两者后续合并时需复核共同改动的语言文件及入门书页。

## 数量与删除

六份静态语言文件的键值统计。改写包含精简与术语修正。未改数字仅反映差异，包含历史兼容和第三方语言覆盖项。

| 语言 | 新增 | 改写 | 未改 | 删除 |
| --- | ---: | ---: | ---: | ---: |
| en_us | 91 | 86 | 1676 | 6 |
| zh_cn | 92 | 86 | 1686 | 6 |

- 从两份主语言文件各删 6 个键。包括旧空白卷轴的 `use`、`risk`，以及 `message.blade_tetra.imprint.*` 的 `no_blade_stand`、`success`、`fail_damaged`、`fail_broken`。逐键确认当前源码、数据资源和手册无引用，旧研习也不再发送这些消息。
- 从动态包移除 `message.blade_tetra.imprint.unsupported_model` 的两种译文。客户端现有外观回退提示走 `visual_fallback`，资格与耐久提示仍保留。
- 删除无调用的神域单段旧对话。当前分支式剧情保留。未删除物品、卷轴、图纸、模型和历史发布记录。
- 精简两组狐系卷轴与动态旧图纸说明、四个觉醒能力悬浮提示、两份发布稿中的旧教程。旧命名、存档标记和动态来源键仍保留。

## 验收与后续

- 静态解析 463 份运行资源 JSON，检查重复键。比对双语键、位置参数和英文静态语言文件中的汉字。11 个仅有中文的键是 Tetra 本体中文补译，英语使用 Tetra 自带资源。
- 静态核对 Patchouli 的 128 份语言目录资源、40 个篇章链接、122 个关联入口和 26 个本模组配方引用。核对进度标题与说明的翻译键，检查 Java 中直接引用的键与动态名刀包。
- 本地尝试使用 Java 17 和 Gradle 8.1.1 编译，ForgeGradle 依赖解析受网络限制。游戏内 Tooltip、魂铭、工作台、剑谱、名刀锭与手册的双语实机显示和文字溢出仍需验证。没有实机截图。
- Contract Blade 旧互操作接口接收刀灵的持久名称字符串，仍沿用「赤月」。更换该接口需要附属协同，已有自定义名称照常显示。旧神域实体已有的字面自定义名按存档原样读取，新实体使用翻译组件。
- 本次核对未确认需要修改的战斗逻辑问题。存档迁移、注册与战斗代码的数值和行为沿用当前基线。
