# 名刀锭材料锻造

名刀锭直接用于现有刀身、刀鞘、刀镡的材料锻造，覆盖13种模块，包括自创流派刀身。不是独立刀身/刀装分支。不支持刀柄、刀环、刀首等其他槽位。保留普通配方的锭数量；仅名刀锭结果固定要求3级锤，普通材料不受影响。

## 公式

A = 来源定义的非负基础攻击，忽略精炼、杀敌、附魔与持有者加成。r=max(1,A)/5，L=log2(r)。round 为四舍五入，clamp为区间限制。

- 材料主值=A。刀身提取0.5A，刀鞘与刀镡各0.25A；允许不同来源混搭。名刀锭刀型仍保留自身攻速、扫击、工具能力与结构差异。攻击不再按普通材料的长刀倍率二次放大。
- 材料耐久=round(clamp(250×r^0.85,120,5000))。再乘普通部件自身的耐久提取系数并加基础值，**不是每个部件都获得整份耐久**。
- 魔容量=round(clamp(84+24L,60,160))。仍由各模块原本的提取系数决定实际获得量；没有容量提取的刀镡不会凭空增加容量。
- 完整度消耗=round(clamp(2+L/1.5,2,5))；供给=round(clamp(5+L,3,8))。仍走模块的原有提取规则；大太刀提取-2时消耗相应加倍。
- 次值=clamp(3.8-0.2L,3,4.6)；三值=clamp(3+0.3L,1,4.5)。只供原本存在对应提取规则的模块使用，不会自动给攻击附送攻速。
- 工具等级/效率原值固定3/4，锻造经验原值固定3。配方的锭用量与经验提取保持原配方；锤需求忽略原配方工具倍率/偏移，固定3。

## 预览、存档与运行开销

- 全息球展示一种通用名刀锭：铁锭轮廓、黑色内芯、红色问号；未指定来源时动态材料属性均为0，展开后的通用模块也不贡献攻击、攻速、耐久、完整度、魔容量、工具或效果数值；乘数保持中性1，避免影响其他部件。固定3级锤与材料用量照常显示。实际有来源的锭保留来源贴图与原计算公式。
- 全息球从已有武器复制预览时，仅清除被替换部件的旧来源和快照，防止通用预览沿用原刀数值；不修改输入武器。通用锭提示“未定其名，尚无其性。／数值随来源名刀而定。”，且仍不能实际用于锻造。
- 放入真实名刀锭时，工作台先记录来源快照，再通过Tetra的模块提取规则计算，与实际成品走同一路径。仅攻击保留精度，避免Tetra逐部件0.5取整破坏25%分配。
- 只增加一种材料及每种支持模块一个变体，不随附属名刀数量增长。派生数据最多缓存512条，材料重载清空；常用属性查询仅取快照攻击值，不重新解码整份来源与效果列表。
- 旧独立仿造配方和新旧刀谱解锁入口退役；旧卷轴仍注册并提示替代路线。
- 明确的legacy_blade/saya/tsuba映射到katana_blade/basic_saya/simple_tsuba；保留槽位强化、附魔、自创流派与其他模组NBT。缺少来源且没有快照，或存在无法解释的模块自有元数据时保留旧兼容模块，不猜测转换。
- 新成品的来源快照在附属缺失后仍供属性/语义读取；外观按现有模型回退规则处理。保持先前的紧凑NBT存储通道。

这些是首轮平衡参数，锤等级不是稀有度证明；实战强度仍需结合来源名刀获取成本与SA/SE体验调整。
