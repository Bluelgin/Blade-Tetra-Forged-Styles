# 连舞流短步追刃 / Rengeki Short-Step

## 设计目标

连舞流继续完整使用《拔刀剑：重锋》的原生 B 系地面连击，不注册新的连舞攻击树，也不增加独立按键、能量条或额外伤害倍率。

本轮只增加一层命中后的短距离位置修正：上一段 B 系连击成功命中后，下一次原生 B 系推进可以向玩家当前视线中的合法目标进行一次有限距离“瞬步”，随后仍由原生 B 系连击继续处理攻击、动画、伤害和命中。

核心定义：

`原生 B 连击 + 命中后一次有限距离短步追身`

## 触发规则

- 只有 `combo_b1` 到 `combo_b6` 的有效伤害命中会开启追刃窗口。
- `combo_b7` 是原生 B 系终段，不再开启新的追刃窗口。
- 追刃窗口持续 `10 tick`。
- 只有真实的原生 B 系推进 `B1→B2`、`B2→B3`、`B3→B4`、`B4→B5`、`B5→B6`、`B6→B7` 才能消费窗口并尝试短步。
- 短步只允许服务器判定为实际着地且未骑乘的玩家触发；离地、坠落、骑乘状态不会借短步强制落地或清除下落动量。
- 方向技、空中技、SA、超时收势等其他 combo 转移会消费当前机会，但不会触发短步，避免稍后出现延迟瞬移。
- 挥空不会产生新的追刃窗口。
- 追刃绑定命中时实际持有的同一把 ItemStack；10 tick 内切到另一把连舞刀不会继承旧刀的短步机会。

这里刻意不直接监听鼠标状态。重锋客户端持续同步的是 `L_DOWN/R_DOWN`，而真正用于 `progressCombo` 的瞬时 `L_CLICK/R_CLICK` 由 `ItemSlashBlade` 在攻击入口临时注入。短步因此监听重锋自己的 `BladeMotionEvent`，直接绑定服务器实际发生的 B 系 combo 转移，避免输入同步时序误判。

## 目标选择

短步不是自动锁敌。玩家仍必须主动转动视角寻找下一名敌人。

候选目标必须同时满足：

- 目标碰撞箱距离玩家不超过 `5.5` 格；大型 Boss 不会因为模型中心很高或很宽而被错误排除。
- 位于视野前方约 `±50°` 内。
- 与玩家高度差不超过 `1.25` 格。
- 玩家对目标有正常视线，不允许隔墙选择。
- 目标仍存活、可攻击且不是友军。
- 目标还必须通过《拔刀剑：重锋》自己的 `AttackablePredicate`，因此 `PVP_ENABLE`、`FRIENDLY_ENABLE`、特殊目标规则与原生 B 系保持一致。
- 玩家目标额外遵守服务器自身 PvP / team 规则。

多个目标同时满足时，优先选择最接近准星中心的目标；角度几乎相同时再选择更近的目标。

## 短步距离

- 单次实际移动距离最多 `2.75` 格。
- 即使目标位于 `5.5` 格搜索范围边缘，也不会一次直接贴到目标身边。
- 移动终点会保留目标碰撞箱外的安全攻击距离，而不是瞬移进目标中心。
- 已经足够贴近目标时不会为了制造位移而强制移动。

搜索距离与移动距离分离是刻意设计：搜索范围用于判断下一名合法追击目标，移动上限负责限制位移能力和异常场景风险。

## 安全路径

短步采用保守的整段路径检查，而不是只检查终点。

从起点到终点每约 `0.35` 格采样一次；任一采样点出现以下情况都会取消移动：

- 玩家完整碰撞箱覆盖到的任一相邻区块未加载；
- 玩家碰撞箱会进入实体方块；
- 脚下没有可站立支撑面；
- 路径跨过沟、悬空区域或其他明显断层。

目标本身还必须通过原版视线检测，因此短步不会穿墙追击。

如果任何检查失败，**只取消短步，不取消 combo 转移，不改写 combo state**。玩家会原地继续《拔刀剑：重锋》的原生 B 连击。

## 状态清理

追刃是纯服务器瞬时状态，不写入物品 NBT、玩家存档或网络协议。

以下情况会丢弃当前追刃机会：

- 10 tick 到期；
- 下一次 combo 转移不是对应的 B→B 推进；
- 玩家切换到非连舞刀；
- 玩家换成另一把连舞刀；
- combo 转移被其他模组取消；
- 玩家已经离地或处于骑乘状态；
- 换维度；
- 退出服务器；
- 死亡后玩家实体 Clone / 重建。

## 战斗结果

### 单体

敌人因为 B 系多段攻击轻微位移后，玩家可以在下一段前短步补位，使后续 B 连段更容易继续命中。

### 群体

B 系命中 A 后，玩家可以主动把视角转向 B；下一次原生 B 系推进会尝试向 B 短步，再由下一段 B 连击继续攻击。玩家仍决定“追谁”，系统只负责有限的位置修正。

## 明确不做

本轮不加入：

- 新的连舞 ComboState；
- 自动连续瞬移；
- 远距离锁敌或跨越地形；
- 瞬步额外伤害倍率；
- 新 HUD / 资源条；
- 强制镜头转向；
- 本传、居合、断岳改动。

## 实机验收

1. 单体：B1 命中后目标退开，继续普通攻击，确认最多只向前补位 2.75 格并正常进入 B2。
2. 连续段：分别检查 B2→B3、B3→B4、B4→B5、B5→B6、B6→B7 都只在前一段成功命中后追身。
3. 近距离：已经贴脸时继续连击，不应出现多余抖动或强制瞬移。
4. 群体：A 命中后转向 B，确认优先追准星方向而不是纯最近目标。
5. 友好目标：关闭重锋 `FRIENDLY_ENABLE` 后，动物等原生 B 不会攻击的目标也不能成为追身目标。
6. PvP：关闭重锋 `PVP_ENABLE` 或服务器 PvP、以及友军目标，都不应成为追身目标。
7. 墙后：目标在 5.5 格内但隔墙，确认不移动且 B 连击仍正常执行。
8. 沟壑：目标在沟另一侧，确认路径采样因缺少地面支撑而取消短步。
9. 区块边界：玩家碰撞箱跨到未加载相邻区块时不应执行短步。
10. 高低差：目标高度差超过 1.25 格，确认不追。
11. 离地 / 骑乘：跳起、被击飞、坠落或骑乘时推进 B 系，不应触发追身，也不应清除 fallDistance。
12. B7：终段命中后继续输入，不应额外触发连舞短步。
13. 方向技 / 空战 / SA：从连舞主动切入其他 combo 时，不应储存一次稍后才触发的短步。
14. 双刀切换：A 连舞刀命中后立刻切 B 连舞刀，B 不应继承 A 的追刃。
15. 大型 Boss：靠近大型目标碰撞箱时，搜索距离应按实际身体距离而不是模型中心错误拒绝。
16. 切换刀身 / 换维度 / 死亡重生 / 退出服务器后，不应残留旧追刃窗口。
