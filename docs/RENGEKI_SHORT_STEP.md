# 连舞流追刃与击杀续舞 / Rengeki Flow

## 设计目标

连舞流继续完整使用《拔刀剑：重锋》的原生 B 系地面连击，不注册新的连舞攻击树，也不增加独立按键、能量条或额外攻击段。

本轮把连舞的核心进一步明确为：**用少量单段伤害换连续追击节奏**。

核心定义：

`原生 B 连击 × 0.92 伤害 + 命中追身 + 击杀自动续舞`

玩家仍负责决定攻击时机和大方向；系统只在合法、安全的范围内帮助连舞不断档。

## 伤害取舍

- `combo_b1` 到 `combo_b7` 以及它们原生收势节点生成的 B 系刀光伤害统一乘 `0.92`。
- 只削弱原生 B 系本身。
- 方向技、空中技、SA、SE、融合技不受这个倍率影响。
- 追身和击杀续舞本身都不会额外补伤害。

这样连舞的收益从“单段数字”转向“更高的持续贴身率、换目标效率和连段稳定性”。

## 普通命中追刃

- `combo_b1` 到 `combo_b6` 的有效非致死命中会开启追刃窗口。
- `combo_b7` 是原生 B 系终段，不会开启普通追刃窗口。
- 追刃窗口持续 `10 tick`。
- 只有真实的原生 B 系推进 `B1→B2`、`B2→B3`、`B3→B4`、`B4→B5`、`B5→B6`、`B6→B7` 才能消费窗口并尝试短步。
- 普通追身搜索距离为 `5.5` 格，视野约 `±50°`，单次实际移动最多 `2.75` 格。
- 方向技、空中技、SA、超时收势等其他 combo 转移会消费当前普通追刃机会，但不会触发短步。
- 挥空不会产生新的追刃窗口。

这里刻意不直接监听鼠标状态。重锋客户端持续同步的是 `L_DOWN/R_DOWN`，而真正用于 `progressCombo` 的瞬时 `L_CLICK/R_CLICK` 由 `ItemSlashBlade` 在攻击入口临时注入。追刃因此监听重锋自己的 `BladeMotionEvent`，直接绑定服务器实际发生的 B 系 combo 转移，避免输入同步时序误判。

## 击杀续舞

任何 `combo_b1` 到 `combo_b7` 的原生 B 系命中，只要这一击确认把目标击杀，就会改为生成一次“击杀续舞”请求，而不是普通追刃窗口。

### 延迟刀光与尾势

重锋的 B 系刀光是实体效果，生成后通常还会延迟若干 tick 才真正造成伤害。因此 B2–B7 的后几发刀光命中时，攻击节点本身可能已经进入 `combo_b_end`、`combo_b7_end` 或 B1 的收势节点。

这些**原生 B 收势状态仍被视为连舞的一部分**：残留 B 刀光在尾势期间击杀目标，仍然允许触发击杀续舞。

但如果玩家已经主动切入方向技、空中技、SA 或其他非 B 分支，则旧 B 刀光之后才造成的击杀不会强行触发续舞。这样可以同时满足：

- 正常 B 连舞的残留刀光不会因为时序晚几 tick 而漏掉击杀奖励；
- 玩家主动切招之后，不会被旧攻击突然抢走位置控制权。

### 为什么不是在 HitEvent 当场瞬移

重锋的一次刀光可能正在同一帧遍历多个命中目标。如果在第一个目标死亡的 `HitEvent` 内立刻改变玩家位置，后续同一刀光的命中结算会出现位置语义混乱。

因此击杀续舞采用两级触发：

1. 如果玩家马上输入下一段真实 B→B 连击，击杀续舞会优先在这次 combo 推进时触发；
2. 如果玩家没有立刻输入，服务器会在下一 tick 自动执行一次续舞移动。

这样既不会干扰当前攻击结算，也能把实际体感控制在约 `50 ms` 内。

### 击杀续舞参数

- 搜索距离：`6.5` 格。
- 搜索角度：前方约 `±80°`。
- 单次最大移动：`4.5` 格。
- 不强制旋转镜头。
- 不自动追加攻击。
- 不额外增加伤害。
- `B7` 击杀同样允许触发，因为它虽然是终段，但击杀后的换目标节奏仍然需要延续。

击杀续舞比普通追刃更积极，但仍然不是 360° 自动索敌。玩家大致面对战斗区域即可获得连续换目标能力，同时不会被突然拉向背后的敌人。

如果下一名目标已经足够近，不会为了制造效果而强制位移。

## 目标选择

普通追刃和击杀续舞共用同一套合法目标规则，只是搜索范围和角度不同。

候选目标必须同时满足：

- 目标碰撞箱处于对应搜索距离内；大型 Boss 不会因为模型中心很高或很宽而被错误排除。
- 与玩家高度差不超过 `1.25` 格。
- 玩家对目标有正常视线，不允许隔墙选择。
- 目标仍存活、可攻击且不是友军。
- 目标必须通过《拔刀剑：重锋》自己的 `SlashBladeTargetingConditions + AttackablePredicate`，因此 `PVP_ENABLE`、`FRIENDLY_ENABLE`、复仇目标等行为与原生 B 系保持一致。
- 玩家目标额外遵守服务器自身 PvP / team 规则。

多个目标同时满足时，优先选择最接近准星中心的目标；角度几乎相同时再选择更近的目标。

## 安全路径

普通追刃和击杀续舞都采用保守的整段路径检查，而不是只检查终点。

从起点到终点每约 `0.35` 格采样一次；任一采样点出现以下情况都会取消移动：

- 玩家完整碰撞箱覆盖到的任一相邻区块未加载；
- 玩家碰撞箱会进入实体方块；
- 脚下没有可站立支撑面；
- 路径跨过沟、悬空区域或其他明显断层。

目标本身还必须通过原版视线检测，因此不会穿墙追击。

如果任何检查失败，**只取消移动，不取消 combo，不改写 combo state**。

## 地面与状态限制

普通追刃和击杀续舞都只允许服务器判定为实际着地且未骑乘的玩家执行。

因此不会出现：

- 跳起后被瞬步强制吸回地面；
- 坠落时借瞬步清除 fallDistance；
- 骑乘状态下把坐骑和玩家位置逻辑撕开。

追刃与击杀续舞都绑定命中时实际持有的同一把 `ItemStack`。切换到另一把连舞刀也不会继承旧刀生成的移动机会。

以下情况会清理瞬时状态：

- 窗口到期；
- 切换到非连舞刀；
- 换成另一把连舞刀；
- combo 转移被其他模组取消；
- 主动切入不对应的 combo 分支；
- 换维度；
- 退出服务器；
- 死亡后玩家实体 Clone / 重建。

所有状态都只存在于服务器内存，不写入物品 NBT、玩家存档或网络协议。

## 战斗结果

### 单体

原生 B 系每段伤害略低，但目标被击退或产生位移后，下一段更容易重新贴住，减少“打到一半因为距离断掉”的情况。

### 群体

对 A 连舞并击杀后，如果前方还有 B，系统会自动把玩家安全地送向 B；下一次输入仍由玩家决定，因此形成：

`击杀 A → 自动续舞到 B → 玩家继续 B 系 → 击杀 B → 继续转移`

目标越密集，连舞越有“舞起来”的感觉，而不是每杀一只都重新走位找怪。

## 明确不做

本轮不加入：

- 新的连舞 ComboState；
- 360° 背后自动索敌；
- 自动连续出刀；
- 击杀后的额外伤害；
- 穿墙、跨沟或无视碰撞的长距离瞬移；
- 新 HUD / 资源条；
- 强制镜头转向；
- 本传、居合、断岳改动。

## 实机验收

1. 伤害：分别检查 B1–B7 及其原生收势刀光，确认 B 系伤害约为原来的 `92%`，方向技/空战/SA 不受影响。
2. 普通单体：B1 非致死命中后目标退开，继续攻击，确认最多补位 `2.75` 格并正常进入 B2。
3. 普通连续段：B2→B3 到 B6→B7 都只在前一段成功非致死命中后获得普通追身。
4. 击杀续舞：B1–B6 任意一段击杀 A 后，前方存在 B 时，应在下一次 B 推进前或下一 server tick 自动向 B 移动。
5. 延迟击杀：B2–B7 的残留刀光在 `combo_b_end / combo_b7_end` 等原生尾势中击杀目标，仍应触发续舞。
6. 主动切招：B 残留刀光在玩家已经切入方向技/SA 后才击杀目标，不应把玩家自动拉走。
7. B7 击杀：B7 终段或其原生尾势击杀 A 后仍可以自动向下一目标续舞，但不会生成新的普通 B 追刃窗口。
8. 多杀：同一 tick 内一段 B 刀光击杀多个目标时，不能连续瞬移多次或抖动；一次只保留一个击杀续舞请求。
9. 击杀后没有合法目标时，不移动、不报错、不残留延迟瞬移。
10. 近距离下一目标：目标已经贴脸时不应出现无意义抖动。
11. 群体转移：多个目标存在时，优先靠近当前视线方向，而不是纯最近目标。
12. 背后目标：只有背后敌人时不应突然把玩家拉向身后。
13. 友好目标：关闭重锋 `FRIENDLY_ENABLE` 后，动物等原生 B 不会攻击的目标也不能成为追身或续舞目标。
14. PvP：关闭重锋 `PVP_ENABLE` 或服务器 PvP、以及友军目标，都不应成为追身或续舞目标。
15. 墙后：目标在搜索范围内但隔墙，确认不移动。
16. 沟壑：目标在沟另一侧，确认路径采样因缺少地面支撑而取消移动。
17. 区块边界：玩家碰撞箱跨到未加载相邻区块时不应执行移动。
18. 高低差：目标高度差超过 `1.25` 格，确认不追。
19. 离地 / 骑乘：跳起、被击飞、坠落或骑乘时，不应触发追身或击杀续舞，也不应清除 fallDistance。
20. 方向技 / 空战 / SA：主动切入其他 combo 时，不应储存一次稍后才触发的移动。
21. 双刀切换：A 连舞刀命中或击杀后立刻切 B 连舞刀，B 不应继承 A 的追刃/续舞。
22. 大型 Boss：靠近大型目标碰撞箱时，搜索距离应按实际身体距离而不是模型中心错误拒绝。
23. 换维度 / 死亡重生 / 退出服务器后，不应残留旧追刃或击杀续舞状态。
