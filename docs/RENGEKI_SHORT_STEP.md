# 连舞流短步追刃 / Rengeki Short-Step

## 设计目标

连舞流继续完整使用《拔刀剑：重锋》的原生 B 系地面连击，不注册新的连舞攻击树，也不增加独立按键、能量条或额外伤害倍率。

本轮只增加一层命中后的短距离位置修正：上一段 B 系连击成功命中后，下一次普通地面攻击可以向玩家当前视线中的合法目标进行一次有限距离“瞬步”，随后仍由原生 B 系连击继续处理攻击、动画、伤害和命中。

核心定义：

`原生 B 连击 + 命中后一次有限距离短步追身`

## 触发规则

- 只有 `combo_b1` 到 `combo_b7` 的有效命中会开启追刃窗口。
- 追刃窗口持续 `10 tick`。
- 下一次新按下的普通地面左键或右键会消费该窗口。
- B1–B6 可以在下一次输入前尝试短步；B7 是原生 B 系终段，不在终段之后额外瞬移。
- 方向技、空中技和其他主动分支不会获得短步；如果玩家主动用这些输入打断普通连舞，当前追刃机会同时被消费，避免稍后意外触发。
- 挥空不会产生新的追刃窗口。

## 目标选择

短步不是自动锁敌。玩家仍必须主动转动视角寻找下一名敌人。

候选目标必须同时满足：

- 距离玩家不超过 `5.5` 格。
- 位于视野前方约 `±50°` 内。
- 与玩家高度差不超过 `1.25` 格。
- 玩家对目标有正常视线，不允许隔墙选择。
- 目标仍存活、可攻击且不是友军；玩家目标还要遵守服务器 PvP 规则。

多个目标同时满足时，优先选择最接近准星中心的目标；角度几乎相同时再选择更近的目标。

## 短步距离

- 单次实际移动距离最多 `2.75` 格。
- 即使目标位于 `5.5` 格搜索范围边缘，也不会一次直接贴到目标身边。
- 移动终点会保留目标碰撞箱外的安全攻击距离，而不是瞬移进目标中心。
- 已经足够贴近目标时不会为了制造位移而强制移动。

搜索距离与移动距离分离是刻意设计：搜索范围用于判断下一名合法追击目标，移动上限负责限制位移能力和异常场景风险。

## 安全路径

短步采用保守的整段路径检查，而不是只检查终点。

从起点到终点每约 `0.35` 格采样一次；任一采样点出现以下情况都会取消移动：

- 区块未加载；
- 玩家碰撞箱会进入实体方块；
- 脚下没有可站立支撑面；
- 路径跨过沟、悬空区域或其他明显断层。

目标本身还必须通过原版视线检测，因此短步不会穿墙追击。

如果任何检查失败，**只取消短步，不取消攻击输入，不改写 combo state**。玩家会原地继续《拔刀剑：重锋》的原生 B 连击。

## 战斗结果

### 单体

敌人因为 B 系多段攻击轻微位移后，玩家可以在下一段前短步补位，使后续 B 连段更容易继续命中。

### 群体

B 系命中 A 后，玩家可以主动把视角转向 B；下一次普通攻击会尝试向 B 短步，再由原生 B 系下一段继续攻击。玩家仍决定“追谁”，系统只负责有限的位置修正。

## 明确不做

本轮不加入：

- 新的连舞 ComboState；
- 自动连续瞬移；
- 远距离锁敌或跨越地形；
- 瞬步额外伤害倍率；
- 新 HUD / 资源条；
- 强制镜头转向；
- 本传、居合、断岳改动。

## 实机验收

1. 单体：B1 命中后目标退开，继续普通攻击，确认最多只向前补位 2.75 格并正常进入下一段 B 连击。
2. 近距离：已经贴脸时继续连击，不应出现多余抖动或强制瞬移。
3. 群体：A 命中后转向 B，确认优先追准星方向而不是纯最近目标。
4. 墙后：目标在 5.5 格内但隔墙，确认不移动且 B 连击仍正常执行。
5. 沟壑：目标在沟另一侧，确认路径采样因缺少地面支撑而取消短步。
6. 高低差：目标高度差超过 1.25 格，确认不追。
7. B7：终段命中后继续输入，不应额外触发连舞短步。
8. 方向技 / 空战：从连舞主动切入通用方向技或空中技时，不应储存一次稍后才触发的短步。
9. PvP：关闭 PvP 或友军目标不应成为追身目标。
10. 切换刀身 / 换维度 / 退出服务器后，不应残留旧追刃窗口。
