# 千本樱：续连宽限与六式碎刃接力

继续更新 PR #45，保留原生下劈散华、上挑凝刃、觉醒条件、真实镡柄/刀鞘、同一碎刃池及现有协议21。其他刀魂和普通连舞不受影响。

## 操作与资源

- 凝刃积攒原生 Rank；散华首次进入 B 连段要求 A 级，锁定这轮入场等级的燃烧效率。
- 长按**左键攻击**持续衔接 B1–B6；松开后不再自动续招。长按右键继续原生 SA 蓄力，不被自动接招重置。
- 连段中点按左/右攻击可缓存一次接招。缓存绑定当前刀对象、槽位、维度、combo 和动作时间，14 tick 到期；虚拟路由不会写入、消耗或刷新缓存。自动尝试只消费一次，包括提交被取消的情况。动作刚提交的同 tick 不重复缓存起手输入。
- B6 七次原生回调全部完成后才能接 B1；其动画、速度、回调不变，额外输入尾窗从100ms扩为500ms。自动输入在 B1 tick9、B2–B5 tick6末、B6 tick7末检查合法原生衔接；普通手动输入继续采用原生窗口。
- 自动衔接发生在玩家 END tick，物品 inventoryTick 此时已执行，所以实际新动作提交成功后，立即执行**新节点 tick0 一次**。下一次 inventoryTick 正常执行 tick1。否则 B2–B6 每招会漏掉 tick0 攻击。取消或重写未成为预期节点时不补回调。
- 暂时离开 B 攻击后保留 **14 tick / 0.7秒**续连资格；边界内重新进入沿用入场效率，即使已降至 A 以下。宽限仍按原10tick时钟扣费，重新进入不重置付款时间。原生 Rank 自然衰减照常存在。
- 资格过期后重新开一轮仍要求 A，并需要新动作提交；重新装备旧的进行中动作不能自动开启。没有额外资源条，散华增益继续被单调 Rank 上限拒绝。资源不足或耗尽禁止自动续招；当前原生动作自然完成，散华保留。
- 上挑凝刃、实际提交的 SA、换刀/槽位、死亡、重生、退出、跨维度清除相应资格/缓存。方向技、空中技不被自动接招代替；不合成方向键，也不增加霸体、伤害、追踪范围或无敌帧修改。

## 六式碎刃

| 招式 | 编排 | 标准48片池的最大调动数 |
| --- | --- | --- |
| B1 | 左翼切入，开场6tick行程后横切 | 8 |
| B2 | 右翼反向横切 | 8 |
| B3 | 两侧交叉向内切割 | 12 |
| B4 | 反向斜交，接续前式回流 | 12 |
| B5 | 多层展开压制 | 16 |
| B6 | 七束错峰出击，穿插后逐束回阵 | 24 |

实际数量受当前空闲碎刃限制，飞行索引不被抢占或重复绘制。B6在24/48/72片三个画质级别保留七束时序，空闲池分别最多调动12/24/36片。仍最多6个并发动作组、8个玩家池及现有总绘制预算。

`SakuraShardChoreography` 定义调度、六式切割曲线和各式行程；`SakuraShardPool` 继续拥有唯一碎刃对象、索引、过渡、回流和可见度。B6七束对应动作tick0–6依次离阵，经过2tick切入后穿过目标区域；**碎刃飞抵存在行程，不声称与七次原生伤害逐帧重合**。真实伤害保持原生时刻，命中高光由服务器实际伤害确认。B1首次6tick行程对应其延迟刀光。

旧统一回旋改为经过攻击区域的横切、斜交和穿插。回流终点跟随移动中的原索引阵位；下一轮调动其余空闲碎刃，不必等待全阵归位。目标死亡/卸载/超距时，现有组固定最后位置完成当前轨迹再回阵；新动作可取新目标，旧碎刃不突然拐向新敌人。

动作视觉在检查实际 combo/动作时间后发送。BladeMotionEvent 在状态提交前触发，可能随后取消；立即攻击由已提交状态下的 DoSlash 兜底，延迟B1由 END 检查确认，避免取消的缓存接招发出虚假出击。继续复用每动作一次 SWING / 至多一次真实 HIT，不增加逐tick位置同步或伤害实体。
