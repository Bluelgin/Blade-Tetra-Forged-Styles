# 觉醒刀 2.0 · Java 接入记录

**基线：** Astra 美术 PR #40 的 `art/awakened-blades-v2` 分支；本代码 PR 以此为 base（堆叠 PR），不要直接把重复美术文件提交到 main。

## 已接入的实际流程

- **旧存档兼容：** 继续读取 `SoulLegacyState`、各刀解锁布尔标记、Tetra 魂铭槽位；保留所有原仪式判定/发成就/播放原音效。首次解锁后多发一条 `AwakenedBladeVfxPacket.AWAKEN` 服务端确认消息。
- **赤月：** 有效命中按照相对角度分为六扇区，不同扇区形成独立因果斩线。至少三方向且存在真正交错角后，成功 SA 预约 **12 tick 后**的因果裁断；结算时重新核查持刀 UUID、原目标、与原标记位置的距离、视线及服务器维度。脱离标记区可闪避；单次伤害总预算≤30，冷却100 tick，退回旧战斗可关闭配置。
- **镜花：** 记录最近三次经服务端验证的真实命中：原生 ComboState ID、攻方位置、目标命中锚点、玩家 yaw/pitch 与实际伤害。至少两次 + 成功 SA 按5 tick间隔重演原方位；超出原目标锚点3格即不命中。命中时创建**无伤的原生 SlashBlade EntitySlashEffect 视觉动作**，伤害则由有上限的独立判定结算。尚未记录或重播完整玩家骨骼动画。
- **千本樱：** 潜行+成功 SA 在凝刃与散华之间切换（NBT存储）。**只有散华的真实命中才积累剑势**，每三次有效命中预约一次安全的短延迟樱刃反击。≥三格剑势时成功 SA 按**地面环阵/冲刺扇阵/空中剑雨**选择不同空间范围，最多5个有效敌人共享一次≤26的总伤害预算，Astra 客户端碎刃最多32片，没有大量 AI 实体。刀身渲染尚未真正隐藏。
- **雷切：** 潜行+成功 SA 在最多3.5格内逐段检测 AABB 后由服务器传送；雷步后的22tick命中窗口内必须实际命中敌人才算**雷步确认**，下一步可升级，最多三段，之后再做 SA 触发≤20伤害终击。未命中只允许重开一段，不凭连续按键获得连段升级。客户端依据真实起终点渲染路径，位移与命中均由服务端判定。

四把刀均通过服务器 `LivingDamageEvent` 确认真实伤害；统一拒绝友军、玩家、驯服动物、村民和多数中立目标。继承既有 `SoulLegacyDamageGuard` 消除二次递归。资源跟随玩家+刀 UUID，不使用客户端反馈来计算伤害。目标换人或超过 160 tick 不命中时，清除暂存能量。服务器停机和卸载维度时回收运行状态。

## 输入与表现

使用重锋原生 Slash Art 成功事件；**不增加按键**。四个技能都可依赖原生 SA，千本樱和雷切用玩家潜行状态切换分支。具体原生 SA 仍会照常执行（V2 的释放是附加事件，并非替代整个 Slash Art 动画）。

新增 `AwakenedBladeVfxPacket` 消息 ID 21 和 `AwakenedBladeStatePacket` 消息 ID 22，协议版本 15 → **16**。使用美术已交付的真实 atlas，遵循 0.5px 内缩 UV，按刀魂合并提交透明四边形；部分动态纹理使用独立动画图集按帧选 UV，真名符纹使用 Astra 正式资源。**四种觉醒增加了44tick独立分阶段演出**，不修改原成就和音效。HUD 图标显示服务器确认的剑势/镜影/斩线/雷荷，读主手刀 UUID，不从客户端攻击动画推算数值。基础效果时长按 Astra 时间轴 18/22/40/44/56/64 tick 选择；使用原有客户端视觉开关、距离与最大效果预算。

### 验收重点

1. 用原版本已觉醒的四把刀载入新版本：不丢觉醒、不重新发成就、普通攻击可正常命中。
2. 赤月绕目标至少三个不同方向命中后成功 SA；相同方向重复攻击不刷斩线。
3. 镜花连续真实命中后 SA：确认连续三次以内的重演且在换刀、切换维度、目标死亡时取消。
4. 千本樱潜行 SA 切换姿态；散华命中三次以上后普通 SA 释放编队，友军不受伤。
5. 雷切潜行 SA 向前雷步，贴墙不得穿过实体碰撞；普通 SA 消耗雷荷触发斩击。
6. 双人同屏与低画质时，检查图集 UV、透明度和遮挡；将 `enableBladeCombatVfx` 关闭后伤害结果不变。
7. 专用服务器连接要求客户端同步更新协议 16。

### 尚需专门的后续工作

- 当前双魂铭刻**仅由优先级最高的一魂**驱动 V2；旧 `SoulResonance` 组合的旧战斗派生不作为本轮新战斗核心。在确定六种新组合前，不宣称双魂专属终结已经完成。
- 镜花的攻击重演目前记录真实伤害与刀光方向，不包含完整玩家模型姿态重播；残影人物模型 pass 仍需额外动画/渲染桥接。
- 千本樱目前是散华战斗资源和编队释放，不会真的隐藏 Tetra 原刀身模型；需适配模块化模型的 renderer 才能做到完整碎刃刀身。
- 44tick觉醒演出已按四种素材类型拆分阶段；**真名解放终结技**的完整56/64tick逐镜头合成、世界内本地化真名文字、真正雷步模型残影和复杂模型材质 pass 仍需后续接入。
- 本环境无法拉取 Gradle wrapper 与 Forge 依赖，构建/专服/实机验证应以 GitHub Actions 和用户客户端为准；**未测试的项目不得标记通过**。

## 兼容与回退

服务器配置 `serverconfig/blade-tetra-server.toml` 中的 `discoveries.enableAwakenedV2` 默认为 `true`。关闭后旧四刀战斗逻辑恢复，新战斗队列在服务器 tick 上立即清理；不会删除任何觉醒进度或武器数据。双魂目前仍是单个主魂的 V2 战斗逻辑，切勿把旧 `SoulResonance` 视为已经重做。

## 性能上限

每次攻击仅保存最近三个镜像记录或少量整数；临时状态最多 512 个 player-blade 实例；镜像待结算≤96、因果队列≤64、短延迟樱刃队列≤64，均按玩家、原武器和维度重新验证。每次终结最多 5 个敌人的额外伤害，镜花最多 3 次延迟伤害。美术仅在玩家 64 格内发消息，客户端按既有可见距离丢弃，最多缓存已有配置的效果数量，樱阵每次不超过 32 个纯装饰小平面。没有全局每 tick 实体扫描。旧镜花、千本樱、雷切的延迟攻击队列在V2开启后会被清空，避免跨版本叠伤；V2二次伤害有独立保护与继承伤害标记，恢复PVE目标的独立受击判定，但不对玩家、友军或驯服实体造成连锁攻击。
