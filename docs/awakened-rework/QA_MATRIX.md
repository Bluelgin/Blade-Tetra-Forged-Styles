# 觉醒刀 2.0：发布前手动与服务器验收清单

本文是**待执行的验收步骤**，不是已经通过的证明；不应因 CI Build 成功而自动勾选。

## 环境与合并顺序

- Minecraft 1.20.1、Forge 47、Java 17、当前仓库定义的 Tetra 与 SlashBlade Resharped 版本。
- 先合并 Astra 美术 #40，再将 Java #41 目标分支改为 main 并执行独立审核。
- 同时测试单机内置服务器和真正的 dedicated server（至少两名玩家）。
- 旧档先**复制备份**再测试：各持一把已解锁的觉醒刀、三组不同刀身材料，以及至少一把已形成双魂的旧刀。
- 网络协议 **17**：客户端和服务器必须使用同一构建。旧协议16应拒绝连接，而非静默丢失渲染消息。
- 服务器配置 `discoveries.enableAwakenedV2` 可切回旧体系；`discoveries.enableAwakenedRankCosts` 可独立关闭评分消耗，以拆分战斗/经济相关问题。

## 镜花水月——真实六帧人物骨骼回放

- [ ] 第三人称命中一个敌人：记录玩家当时的皮肤、手臂、腿部、身体和衣装的短姿态片段，最多6帧，不生成伤害实体。
- [ ] 连续两到三次真实命中后达 A Rank 并成功使用 SA：24/29/34 tick 依次在**原出刀位置**出现短暂半透明玩家模型和原生刀光。
- [ ] 第一人称镜影至少能显示保底 PlayerModel 姿态，不发生崩溃、手臂畸形；此模式可能不如第三人称骨骼快照精确。
- [ ] 在命中后移动到其他位置再释放：残影站在原来位置，不瞬移到玩家当前坐标。
- [ ] 目标逃离原记录区域3格以上 / 死亡 / 被换成友军 / 隔墙 / 换刀 / 跨维度：无旧镜影二次伤害。
- [ ] 玩家离开视野、低画质禁用VFX、切维度、退出再进世界：客户端快照队列及时释放，玩家原模型姿态不被残影渲染篡改。
- [ ] 协奏「镜月/镜樱/镜雷」都只付一次 Rank，不重复结算原本的实体伤害。

## 赤月——空间裁断

- [ ] 围绕敌人从至少3个不同且有效交错扇区攻击：只产生正确扇区的斩线，重复扇区不无限刷。
- [ ] 达到 S Rank、成功 SA：第33 tick 才触发真实结算，对应斩线/节点/十字逐层播放。
- [ ] 目标在33tick前逃离原锚点5格以上 / 遮挡视线 / 玩家换刀：无法凭旧位置必中。
- [ ] 低于S或原生Rank分数不足：不消费 Rank，不提交新裁断，原生基础攻击仍正常。
- [ ] 双魂「镜月/葬樱/赤雷」只收一笔 S Rank基础费+双魂附加费。

## 千本樱——实体刀身分解/三套剑阵

- [ ] 潜行 + SA 切换散华时，真正的 OBJ `blade` 和发光刀身消失，刀鞘、物品图标、Tetra 材质不受影响。
- [ ] 散华附近有不超过9片低频环绕碎刃；凝刃恢复原物理刀身，换材质后亦能恢复。
- [ ] 非散华状态不积累剑势。散华真实命中3次积蓄剑势，出现独立小型樱刃回击。
- [ ] 地面站定普通SA：环形护阵；地面冲刺普通SA：朝前扇阵；空中普通SA：剑雨。确认不同空间范围和阵型正确。
- [ ] 单次剑阵最多5目标共享≤26伤害预算，28/31/34/37/40 tick与视觉同步；友军、玩家、驯养动物均不受伤。
- [ ] 原生多种第三方 OBJ 分组、物品栏、第一/第三人称、双持、副手等不隐藏其它刀部件（`RenderOverrideEvent` 仅针对本刀NBT）。

## 雷切——Rank经济与连续雷步

- [ ] 玩家原生B Rank且恰好900点时，可付75点开启第一步。之后Rank可能降为B以下，但成功命中后仍能连续进行第二/第三步，**两次续接不另扣分**。
- [ ] 第一步未命中、第二步超过36tick、第三步之后重新开启：新连段必须再次付费并达到B门槛。
- [ ] 贴墙、不完整碰撞箱、狭窄空间、楼梯：逐0.5格检查不可穿墙或卡入实体。
- [ ] 距离目标8格以内且具备A Rank、足够雷荷时普通SA：实际最多前冲3.5格并造成有限终击，不能无视墙体远距离必中。
- [ ] 双魂赤雷/镜雷的附带位移也服从同一碰撞安全检查。

## 跨系统/性能/经济验证

- [ ] 普通攻击积累原生 Rank，觉醒技通过 `IConcentrationRank.addRankPoint` 真正降低重锋评分，而不是独立的自制条。
- [ ] 0分配置仍检查最低评级；完全关闭 `enableAwakenedRankCosts` 后才可免评级/免支付。修改单刀与双魂价格后HUD正确同步。
- [ ] 自创剑谱中记录的原生 ComboState 能被镜花正常读取；在新剑谱自定义刀身、重锋原生流派以及各种SA之间无残留状态。
- [ ] Rank高/低下的单刀特殊技、双魂特殊技、冷却与队列满额不会重复扣费。
- [ ] 5分钟密集战斗后 VFX 按可视距离截断，快照最多48条、同时残影最多12个，额外伤害队列有上限；客户端内存稳定。
- [ ] 两人联机时只有持刀者看到自己的HUD，但附近双方均看到觉醒、残影、剑阵和真名文字。
- [ ] 玩家死亡、登出、切维度、专用服务器停机、改为旧V2开关：所有临时状态回收，且旧武器觉醒和成就信息仍在。
- [ ] 低配画质、无皮肤缓存、第三方资源包、旧版本材质图集下显示正常或可靠降级。

## 发布阻断

目前尚无本清单全项的游戏内验收记录。尤其是**玩家模型六帧回放、真实Tetra OBJ渲染取消、多人下Rank评分同步和新机制平衡**需真实客户端操作。若任一环节导致致命崩溃、穿墙或重复伤害，应保持PR Draft，并优先修复，不要自动合并。
