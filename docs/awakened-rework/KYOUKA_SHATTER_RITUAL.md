# 镜花：破镜归刀

本地测试集成保留千本樱 PR #45 的新内容，替换镜花 PR #46 的实时反射仪式。

- 0–20 tick：原刀离手，刀鞘留身。
- 24–54 tick：36 块镜面面片在刀所在位置逐片合拢。
- 56–85 tick：刀隐入镜中，72 tick 起裂纹逐渐亮起。
- 85–94 tick：原刀向玩家方向破镜冲出，同一组面片散开。
- 94–97 tick：碎片短暂停留。
- 97–112 tick：三股弧线碎片归入移动中的原刀。
- 112–120 tick：原刀归手。真名和破镜音效仍对齐 85 tick。

只使用原版纹理颜色着色器和已有白色纹理。移除仪式的世界二次渲染、离屏目标、反射 mixin、自定义镜面 shader、反射质量配置及旧原型。战斗中的镜花反制机制不在移除范围。

面片与裂纹共用仪式会话、距离和视锥剔除、全局面片预算。低档保留全部 36 块碎片，省略额外边线、反光和尾迹。高档单个镜花仪式最多 216 个四边形，无临时实体、独立定时器或 GPU 资源生命周期。
