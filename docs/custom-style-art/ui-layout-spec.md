# UI 布局与像素规范

所有坐标使用 Minecraft **GUI 逻辑像素**，并非窗口物理像素。文字不烘焙进任何生产 PNG。
原生 Minecraft Font 的字号/字宽由实际字体资源决定，概念图中的 CJK 字体只是占位。

## 视觉与采样

配色：轮廓 `#211d2a`，纸 `#e6ddcf`，纸阴影 `#c7b697`，旧金 `#a88651`，
高光 `#dfbd79`，朱红 `#8a2f2f`，兼容/可用文字 `#365a63`。
状态同时使用形状和文字，不依赖红绿区分。每张物品有透明外缘及深轮廓。
物品 PNG 32×32、工作台图标 16×16、状态/操作图标 12×12；最近邻过滤，禁止平滑拉伸。
物品栏由游戏在 16 个逻辑像素内绘制 32px 图标，不添加额外发光 pass。

## A. 轻量 HUD

`recording_hud.png`：160×36，默认左上安全边距 (8,8)，保留中心准星、热栏、生命条和 Boss 条。
建议核心客户端允许移动锚点；遇到其他模组 HUD 时由配置调位，不移动车万/Tetra 元素。
只有核心 `recordingActive=true` 且未打开管理屏幕时显示，不攫取鼠标、键盘焦点，不暂停游戏。

| 元素 | 相对位置/范围 | 行为 |
|---|---|---|
| 状态图标 | (9,6), 12×12 | 形状随核心状态切换 |
| 最近动作/提示 | (26,5), 126×9 | 单行，按字体测宽后裁切 |
| 数量 | (26,24), 50×9 | `recordedActions.size / maxActions`，容量来自核心 |
| 按键提示 | (84,24), 68×9 | 使用真实键位显示名，不硬编码 R |
| 短动画 | 纸色动作行左侧，16×16 | 成功回执后播放，不铺满背景 |

图中 R 与 4/6 均为示例，不代表绑定键位或业务容量。长动作名优先省略前缀，再省略动作名。
超长键位名缩为按键名或在设置说明中完整显示，不能推挤数量区域。
反馈文字在第一行替换 20 tick 后恢复最近动作；失败有形状与原因文字，不能播放成功墨迹。

## B. 剑谱管理

`editor_panel.png`：248×220。原点 `floor((scaledWidth-248)/2), floor((scaledHeight-220)/2)`。
最小目标画布 320×240；适应 GUI Scale 1/2/3/4/Auto 时按当前 scaledWidth/scaledHeight 计算，
不把 GUI Scale 倍率再次乘进坐标。大屏保持固定逻辑尺寸。

| 元素 | 面板相对矩形 x,y,w,h | 规则 |
|---|---|---|
| 标题 | 12,8,212,12 | 居中，单行 |
| 关闭 | 228,6,14,14 | 原生关闭行为，Esc 同义 |
| 流派名称输入 | 12,35,224,18 | 使用原生 EditBox 与焦点框，支持中文输入法 |
| 动作列表/剪裁 | 12,62,224,110 | 5 行可见，每行 22，按原序展示编号 |
| 纵向滚动条 | 234,62,3,110 | 仅列表溢出时显示活动滑块 |
| 数量 | 12,182,224,9 | 超容量/校验失败时显示原因摘要并提供 Tooltip |
| 撤销 | 10,194,52,20 | 操作最后一条，非任意选中行删除 |
| 清空 | 66,194,52,20 | 打开小型原生确认对话框，确认后发送请求 |
| 完成剑谱 | 122,194,116,20 | 校验通过时可提交；等待回执期间禁用重复提交 |

`action_row` 为正常行，`action_row_selected` 仅表示当前焦点/最后回执加入的一行。
编号列 20px，名称始于行内 x=27，可用宽度 189px。焦点不允许拖拽、重排或自行修改动作 ID。
连续序列是按顺序的列表，行号已表明顺序，不插入可能被误认为分支节点的连线。
空列表显示 `empty` 文案；容量示例 6 时第六行需要滚动，不缩小字体。

按钮纹理是 24×20 三段切片：左 3px，中心 18px，右 3px。
渲染成目标宽度时只水平延展中心，左右边帽及高度不变。
四态 `normal / hover / disabled / pressed`，键盘焦点用原生焦点边框。
资源包没有自带按钮处理器，核心须实现原生组件交互和 narration。

缩放导致逻辑画布低于 264×236 时，不整体缩成难读小字：面板高度缩为 H-16，
列表视口缩短到至少一行，标题/输入/底部操作固定，滚动显示其余；宽度低于264时使用
原生滚动/分页容器，按钮可分两行。属于待实现的客户端适配需求，概念图未验证极端分辨率。

## C. Tetra 工作台

不得替换原生工作台底图。选项在 `slashblade/blade` 同级加工分支里展示 `style_custom` 图标；
依旧与现有四流派并列，不能新增装备槽。选项标题使用原生 schematic 名称控件。

- 默认详情区只补充两行：剑谱名称（按原生可用宽度裁切）与 `N 招 · 已识别`。
- 作者、完整动作列表、校验原因置于原生 Tooltip，避免挤占已有材料/属性。
- 在原生模块/规格选择区域展示 `length_short / standard / long`，每项 16px 图标＋本地化短标签。
  概念图的 48×45 三列是可用宽度≥156px时的排法；狭窄详情区逐行列出，沿用原生列表。
- 未展开/不兼容：使用 `state_locked / state_unavailable` 和原因 Tooltip。隐藏还是禁用加工选项
  由 Tetra 与核心现有逻辑决定，美术不得通过变灰强制绕过规则。
- 已识别：`state_recognized` 静态标识。成功加工：在当前结果预览边缘局部播放 `forge_glint`。

工作台 Mockup 是信息层级示意，最终位置必须使用 Tetra 原生控件的实际边界。
不预设 Tetra glyph JSON 可以任意指定贴图 URL；如原生 glyph 仅支持固定图集，需要核心提供适配。

## 中英文与可访问性

`export/ui-strings.json` 提供 34 对同键文本（以实际文件数量为准）。它是合并用片段，不会被游戏自动加载。
核心确认 namespace 后合并进 `assets/blade_tetra/lang/{zh_cn,en_us}.json`。
不要翻译或解析动作 ID；动作名称使用核心返回的本地化 Component。

- 使用 `Font.width` 按像素裁切，保留完整内容的 Tooltip/narration；不能按固定汉字数截断。
- 流派名输入的最大长度、空白名和非法内容规则沿用核心；美术不规定业务限制。
- 189px 行名预算约容纳 20 个常规中文字符或 31 个平均6px英文字符，实际以当前 Font 为准。
- 长作者名和动作名只在固定区域裁切，不延长窗口、按钮或遮挡数量。
- 本地化状态原因最多两行出现在 Tooltip；HUD只显示单行摘要。
- Tab 顺序：名称→列表→撤销→清空→完成→关闭；列表方向键/滚轮导航；Enter 只激活焦点按钮。
- 状态与失败原因提供 narration；禁用按钮也应能通过 Tooltip 解释原因。
- 减少动态效果时以静态状态符替代所有三组动画，保留文字反馈。
